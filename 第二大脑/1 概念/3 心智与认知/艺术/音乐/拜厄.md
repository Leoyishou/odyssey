## 和弦骨架

只用两个音，也能让耳朵听出“稳、回家、推动、紧张、落地”。
**C 大调里的“和声骨架”和“紧张-解决”**。

| 组合              | 乐理上是什么              | 听感为什么这样                  |
| --------------- | ------------------- | ------------------------ |
| **C(do)+E(mi)** | C 大三和弦的 1 音 + 3 音   | 已经能听出 C 大调的“家”           |
| **D(re)+F(fa)** | 2 音 + 4 音，紧张音程      | 它很容易往 C+E 解决             |
| C(do)+G(sol)    | 纯五度，C 和弦的 1 音 + 5 音 | 很空、很稳，像根基                |
| C(do)+C(do)     | 八度                  | 最像“定住了”                  |
| G(sol)+D(re)    | G 的纯五度，属音骨架         | G 是 C 大调的属音，有往前推的感觉      |
| G(sol)+G(sol)   | 属音八度                | 不像 C 那么落地，像还没完           |
| C(do)+E(mi)     | 1 音 + 3 音           | 从 D+F 回到 C+E，就有“落地”感     |
| E(mi)+G(sol)    | C 和弦的 3 音 + 5 音     | 还算稳定，但没有 C 做根音，所以没那么“回家” |
