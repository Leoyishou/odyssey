#  💡Summary  

> [!Info]
> 一句话说清楚
> 

它们不是严格一一对应，教材更像“能力训练线”，考级更像“曲目难度线”。大致可以这样理解：

如果按“十级路径”粗略拆：

| 考级阶段 | 主要能力 | 对应教材 |
|---|---|---|
| 考级前 | 识谱、手型、节奏、双手入门 | 小汤1-2 |
| 1级 | 简单读谱、基本节奏、简单连奏/断奏 | 小汤3、小汤4前半、拜厄前段 |
| 2级 | 手位移动、简单升降号、双手配合稳定 | 小汤4-5、拜厄中段、哈农入门 |
| 3级 | 基础音阶、琶音、左右手独立加强 | 拜厄后段、车尔尼599前段、哈农 |
| 4级 | 跑动、分解和弦、节奏型更复杂 | 车尔尼599中段、哈农 |
| 5级 | 初级到中级过渡，速度和均匀度要求提高 | 车尔尼599后段、可接车尔尼849 |
| 6-7级 | 更复杂音型、复调、踏板、音乐表现 | 车尔尼849、299前段、哈农继续 |
| 8-10级 | 中高级曲目完整性、速度、音色、风格控制 | 车尔尼299/740、巴赫、奏鸣曲、乐曲体系 |

一句话：**小汤基本覆盖考级前到2级，拜厄覆盖1到3级基本功，车尔尼599大约覆盖2到5级技术过渡，哈农从2级以后长期陪跑，一直到高级阶段都能用。**
