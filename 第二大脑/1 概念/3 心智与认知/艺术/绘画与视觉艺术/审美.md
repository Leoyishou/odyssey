```
Design_Universe_Entry/
└── Project(你的设计审美构建)/
    ├── History_&_Styles(流派/时间线-设计史的骨架)/
    │   ├── Early_Modernism(早期现代主义)/
    │   │   ├── Bauhaus(包豪斯 1919-1933)/
    │   │   │   ├── Motto("形式追随功能")✅
    │   │   │   ├── Materials(钢管/皮革/玻璃)
    │   │   │   └── KeyItems(关键单品)/
    │   │   │       └── Wassily Chair (你提到的钢管椅) -> [Marcel Breuer]
    │   │   └── InternationalStyle(国际主义风格)/
    │   │       └── Barcelona Chair (你提到的极简巅峰) -> [Mies van der Rohe]
    │   │
    │   ├── Mid_Century_Modern(MCM 1945-1970 黄金年代)/
    │   │   ├── Characteristics(温暖/有机曲线/胶合板/玻璃钢)✅
    │   │   ├── USA_Branch(美式MCM)/
    │   │   │   ├── Eames_Office/
    │   │   │   │   └── Eames Lounge & Ottoman (你提到的神作)
    │   │   │   └── Knoll_Group/
    │   │   │       ├── Tulip Chair (你提到的未来主义郁金香椅) -> [Saarinen]
    │   │   │       └── Womb Chair (子宫椅)
    │   │   └── Scandi_Design(北欧设计)/
    │   │       ├── Danish_Modern(丹麦现代)/
    │   │       │   ├── Egg/Swan Chair (你提到的蛋椅) -> [Arne Jacobsen]
    │   │       │   └── Panton Chair (S形塑料椅)
    │   │       └── Philosophy(Hygge/以人为本/自然材质)
    │   │
    │   └── Functionalism_to_Minimalism(功能主义到极简)/
    │       ├── German_Braun_Era(博朗时代 1950s-80s)/
    │       │   ├── Dieter_Rams(迪特·拉姆斯)
    │       │   └── "Less but better"
    │       └── Apple_Design(苹果时代)/
    │           ├── Jony_Ive(乔纳森·艾维)
    │           └── Connection: 苹果设计深受博朗影响 (如iPod vs Braun T3收音机)✅
    │
    ├── Inspector(鉴赏维度-怎么看懂一个设计)/
    │   ├── Form(形态)/
    │   │   ├── Geometric(几何形态 - Bauhaus/Braun)
    │   │   └── Organic(有机形态 - Eames/Saarinen)
    │   ├── CMF(Color, Material, Finish - 颜色/材质/表面处理)/
    │   │   ├── Wood(胡桃木/胶合板) -> 温暖感 (Eames)
    │   │   ├── Metal(镀铬钢管/铝合金) -> 工业感 (Macintosh/Wassily)
    │   │   └── Plastic(聚碳酸酯/玻璃钢) -> 可塑性 (Panton/Ghost)
    │   └── Ergonomics(人机工程学 - 坐感/握持感)
    │
    ├── Masters_&_Brands(人物与厂牌-谁在生产)/
    │   ├── The_Big_Three_Furniture(家具三巨头)/
    │   │   ├── Herman_Miller(美国 - Eames的东家)✅
    │   │   ├── Knoll(美国 - Saarinen/Mies的东家)✅
    │   │   └── Vitra(瑞士 - 拥有Panton/Eames欧洲版权，设计博物馆)✅
    │   └── Tech_&_Lifestyle(科技与生活)/
    │       ├── Apple (加州)
    │       ├── Lamy (德国海德堡 - Bauhaus精神的延续)
    │       ├── Braun (德国)
    │       └── Sony (日本 - 晶体管收音机时代的霸主)
    │
    ├── Output(你的收藏与应用)/
    │   ├── Collecting(收藏)/
    │   │   ├── Vintage(中古/元年版)
    │   │   └── Reproduction(官方复刻版 vs 仿品)
    │   └── Interior_Styling(搭配)/
    │       ├── Mix_&_Match(混搭 - 比如Eames椅配现代公寓)
    │       └── Space_Age(太空时代风格 - Tulip/Panton)
    │
    └── Metadata(进阶资源)/
        ├── Documentary(纪录片)/
        │   ├── "Objectified" (设计面面观 - 必看)✅
        │   └── "Rams" (关于迪特·拉姆斯)
        ├── Books/
        │   └── "Design of the 20th Century" (Taschen出版社)
        └── Places/
            └── MoMA (纽约现代艺术博物馆 - 你提到的很多椅子都在这里)
```
