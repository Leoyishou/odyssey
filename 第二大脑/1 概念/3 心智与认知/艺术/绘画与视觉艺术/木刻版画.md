# 🪞Notes

审美特点

核心美学：「刀味」与「木味」
- 刀味：以刀代笔，画面上每根线条、色块都带有鲜明的雕刻痕迹，粗犷有力
- 木味：利用木材纹理，产生自然的肌理效果
- 黑白对比：通过点线面的疏密关系、刻刀轻重手法，创造独特的层次感
- 质朴练达：体现东方审美的简约与力量感

---
发展背景

| 时期           | 发展阶段     | 特点                                         |
| :------------- | :----------- | :------------------------------------------- |
| 唐代 (公元868年) | 起源期       | 源于雕版印刷术，主要服务宗教（佛经扉页插图） |
| 宋元           | 兴盛期       | 摆脱宗教依赖，题材扩展到天文地理、花鸟鱼虫   |
| 明清           | 民间繁荣     | 木刻年画兴起（朱仙镇、桃花坞、杨柳青等）     |
| 1931年         | 新兴木刻运动 | 鲁迅发起，作为革命宣传武器，提振民族精神     |

---
重要原型/流派
1. 中国传统：唐代佛经版画 → 明清民间年画
2. 日本浮世绘：影响了莫奈、梵高等印象派画家
3. 德国表现主义：丢勒将欧洲木刻推向顶峰
4. 延安木刻：抗战时期的革命艺术，强调「为人民服务」

---
为什么木刻版画有独特魅力？

1. 它是印刷术的副产品，天然带有「复制传播」的基因——廉价、易普及、视觉冲击力强。
2. 黑白分明的对比、刀刻的力度感，特别适合表达强烈情感和社会批判。
3. 这也是为什么鲁迅选择木刻作为唤醒国民的工具——它既是艺术，也是武器。
