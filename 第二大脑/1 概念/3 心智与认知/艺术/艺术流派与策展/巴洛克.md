#  💡Summary  

> [!Info]
> **巴洛克不是装修专属，而是一个欧洲艺术时期/风格**，大约在 **1600-1750 年**，同时存在于[[建筑]]、绘画、[[音乐@]]里。
> 

巴洛克=强烈、有力、宗教/王权；[[洛可可]]=柔美、粉嫩、情爱/神话、贵族日常

# 🪞Notes


| 领域       | 巴洛克表现                    |
| -------- | ------------------------ |
| 装修/建筑    | 华丽、对称、雕花多、金色装饰、戏剧感强      |
| 音乐       | 复调、装饰音多、节奏稳定、层次清楚、舞曲感    |
| [[钢琴]]演奏 | 讲究清晰触键、声部独立、不过度浪漫化、不乱用踏板 |

但要注意一点：**巴洛克时期严格说还不是现代钢琴的时代**。巴赫、亨德尔这些人的键盘作品，原本更多是写给 **羽管键琴、古钢琴、管风琴** 的。今天我们用现代钢琴弹巴赫，就会说“用巴洛克风格处理”。

你截图里的“巴洛克风格要点”主要是在说：弹这类作品时不要弹得太厚、太黏、太浪漫，要更像宫廷舞曲或复调音乐，声音清楚、轻巧、均衡。比如巴赫的小步舞曲、二部创意曲，就很典型。
