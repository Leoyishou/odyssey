> **一句话记忆**  
> “$0$ 起头、后继不循环，归纳贯通全体；加法是递归，乘法是重复加。”——这就是皮亚诺公理为自然数世界建立的五大支柱。

## 皮亚诺算术公理（Peano Axioms）速览

**语言符号**

- 常量：$0$
- 一元函数：$S(x)$ （后继 / 加 1）
- 二元函数：$+, \times$ （若讨论完全版 PA）
- 逻辑符号：$\forall, \exists, \land, \lor, \lnot, \Rightarrow$
- 变量范围：自然数 $\mathbb{N} = \{0,1,2,\dots\}$
    

---

|#|公理内容（经典一阶版本）|直观解读|
|---|---|---|
|**P1**|$0$ 不是任何数的后继：$\forall x (S(x) \neq 0)$|没有“-1”这样的自然数。|
|**P2**|不同数后继不同：$\forall x \forall y (S(x)=S(y) \Rightarrow x=y)$|“加 1”是单射，不会把两个数混为一个。|
|**P3**|**归纳公理**：若对性质 $P$ 有||
| |① $P(0)$ 成立； ② $\forall n (P(n)\Rightarrow P(S(n)))$；| |
| |则 $\forall n P(n)$ 成立。|数学归纳法的本质；保证自然数“只有 $0$ 开头、不断加 1”那一条链。|
|**P4**|$+$ 的递归定义：||
| |① $x+0 = x$| |
| |② $x+S(y)=S(x+y)$|“加 0 不变；加 $S(y)$ 等于先加 $y$ 再 +1”。|
|**P5**|$\times$ 的递归定义：||
| |① $x \times 0 = 0$| |
| |② $x \times S(y) = x \times y + x$|“乘法 = 重复加法”。|

> **说明**
>
> - **最小核心**：P1–P3（只用 $0$ 与后继）即可刻画自然数结构，称 _Robinson Arithmetic_ 的简化版 $Q$。
>
> - **PA (Peano Arithmetic)**：再加上 P4、P5 与一阶逻辑的等式公理，就成为常说的“皮亚诺算术”。
>
> - **二阶 PA**：若把归纳公理写成“对 **所有性质** $P$ 都成立”，需要二阶量词；其模型唯一同构于 $\mathbb{N}$，但失去可判定性。
>

---

### 为什么重要？

1. **形式化奠基**：19 世纪末皮亚诺（G. Peano）用符号逻辑首次系统刻画自然数，为日后元数学研究（哥德尔不完全性定理等）铺路。
    
2. **归纳法合法化**：归纳公理把日常“从 0 开始逐步推出”严格写成逻辑句。
    
3. **可计算理论基石**：在 PA 内可以定义可递归函数、证明基本算术恒真式，是现代计算机科学的逻辑底座之一。
