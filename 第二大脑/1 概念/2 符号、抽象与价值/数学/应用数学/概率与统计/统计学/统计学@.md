# 💡 Summary  

1. 统计学 是一门**应用性科学**：关注如何从数据中获得信息、支持决策；
2. [[数理统计@]] 是其中的**数学部分**：关注抽象的理论、方法的正确性与性质。
	物理学：包括实验物理 + 理论物理  
	统计学：包括[[应用统计]] + [[数理统计@]]
	
```Java
统计学 (Statistics)
│
├── 数理统计 (Mathematical Statistics)   ← 理论基础
│    ├─ 参数估计理论
│    ├─ 假设检验理论
│    └─ 抽样分布、渐近理论
│
├── 应用统计 (Applied Statistics)
│    ├─ 生物统计
│    ├─ 社会经济统计
│    └─ 工程质量控制
│
└── 现代统计分支
     ├─ 贝叶斯统计
     ├─ 计算统计
     └─ 机器学习（统计学习）

```
