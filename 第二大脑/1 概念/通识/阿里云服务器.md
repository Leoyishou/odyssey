# 🪞Notes

| 缩写      | 英文全称                        | 中文名    | 是什么                                               |
| ------- | --------------------------- | ------ | ------------------------------------------------- |
| **RDS** | Relational Database Service | 关系型数据库 | 阿里云托管的数据库服务。你的 PostgreSQL 就跑在这上面，装机、备份、升级都由阿里云负责  |
| **ECS** | Elastic Compute Service     | 弹性计算服务 | 阿里云的云服务器，相当于一台远程电脑，可以在上面跑任何程序，比如 Hindsight API 服务 |
| VPC     | Virtual Private Cloud       | 虚拟私有网络 | RDS 和 ECS 放在同一个 VPC 里，就能走内网连接，数据库不用对公网开放          |
