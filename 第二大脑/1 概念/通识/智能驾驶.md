#  💡Summary  

> [!Info]
> **分级只看一件事：出了事谁负责。** 人负责就是 L2（再强也是辅助驾驶），系统开车时车企负责才算 L3。

| 级别     | 谁在开 / 谁担责                | 现实例子                                                                 |
| ------ | ------------------------ | -------------------------------------------------------------------- |
| L2 / L2+ | 系统帮你开，人必须盯着，责任在人         | 特斯拉 FSD (Supervised)、华为 ADS、小鹏/理想/小米的高速 NOA、城区 NOA                |
| L3     | 限定场景内系统开，车企担责，系统请求时人要接管 | 奔驰、宝马高速限速场景；国内 2025-12 首批准入：长安深蓝 SL03（重庆快速路拥堵，≤50km/h）、极狐阿尔法S（北京指定高速，≤80km/h） |
| L4     | 限定区域内完全不要人               | Waymo、萝卜快跑、特斯拉 Robotaxi（几个城市试运营，规模很小）                            |

# 🪞Notes

## ADS 和 NOA 不是一个层级

- **ADS** = Advanced Driving System，高阶驾驶系统。华为叫「乾崑智驾 ADS」，指整套感知、决策、控制软硬件，高速、城区、泊车都在里面——**是整套系统名**。
- **NOA** = Navigate on Autopilot，导航辅助驾驶 / 领航辅助，特斯拉先用的说法：按导航自动跟车、变道、上下匝道——**是系统里「跟着导航开」那一档功能**。
- **高速 NOA vs 城区 NOA**：高速路况简单（没红绿灯、没电动车），城区要处理路口、行人、加塞，难一个量级。租车卡片上写「城区 NOA」的车，市区也能用辅助驾驶。
- 不管叫啥，**都还是 L2+，手不能离开方向盘**。

## 端到端

- 老做法：感知 → 预测 → 规划 → 控制，一段段手写规则拼起来。
- **端到端**：一个大模型直接从摄像头画面输出方向盘和油门，靠海量驾驶视频学会开车。特斯拉从 FSD v12 开始大规模押上去，背后是几百万辆车回传的数据 + 自建大算力，这两点全球最强。
- 但「领先」要拆开看：数据和算力规模领先；**真正敢不要人**（L4 商业运营）Waymo 比它早、比它多；国内路况的端到端体验，华为、小鹏、理想追得很近。

## 为啥 FSD 再强也只算 L2

车主条款写明司机必须一直盯着、责任在人，法规也按 L2 认定。L3 的门槛不是技术「看起来多能开」，而是车企**敢在合同里认责**。特斯拉没走 L3 这条路，直接从 L2 跳去做 Robotaxi（L4）。
