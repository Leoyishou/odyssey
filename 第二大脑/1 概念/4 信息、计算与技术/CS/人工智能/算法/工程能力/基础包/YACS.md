# Notes

YACS = Yet Another Configuration System（又一个配置系统）

这是 Facebook Research（现 Meta）开发的一个 Python 配置库，专门用于深度学习项目的超参数管理。

## 🏛️ YACS 的起源

YACS 最初在 Facebook 的计算机视觉项目中流行：
- Detectron（目标检测框架）
- Detectron2（更现代的版本）
- Mask R-CNN 等

GitHub: facebookresearch/yacs (约 3k+ stars)
