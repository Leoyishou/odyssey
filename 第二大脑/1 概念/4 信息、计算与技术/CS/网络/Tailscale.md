# 🪞Notes

## 和内网穿透有啥不同

| | [[内网穿透]]（ngrok、frp） | Tailscale |
| --- | --- | --- |
| 方向 | 把**一个服务**暴露到公网，谁拿到链接都能访问 | 把**一组设备**拉进同一个私有网，外人看不到 |
| 比喻 | 在自家墙上开个对外窗口 | 给几栋楼之间修了条只有自己人能走的地下通道 |
| 典型用法 | 临时给客户看本地项目 | 在外面用手机 [[SSH]] 回家里 Mac、几台机器互相调服务 |

## 怎么做到的

- **WireGuard**：一个很轻的 VPN 协议，代码量小、加密强、连接快。手搓 WireGuard 要自己配每台机器的公钥、IP、路由。
- **Tailscale**：在 WireGuard 上加了一层「控制面」——登录同一个账号，自动发钥匙、分地址（`100.x.y.z` 段）、打洞直连；打不通时走它的中继服务器。
- 所以你 [[局域网]] 里记的 Mac「门牌号」`100.84.194.21`，大概率就是 Tailscale 分的地址（待核），不是家里路由器分的。

## 为啥 DHH 在国内用 Claude Code 要先走 Tailscale

把流量先绕进自己这套网络里的某台海外机器（exit node，出口节点），再从那里出公网，连接更稳——本质上是把 Tailscale 当成了一个自建的出口。

> 来源：调研 bot 10-21 15:34（DHH 那条推），10-22 01:14（希望各家 agent 能通过 Tailscale 内网互相通信）。
