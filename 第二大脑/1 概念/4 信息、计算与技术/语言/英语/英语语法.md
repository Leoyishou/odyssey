> [!Info]
> **英语不是单纯按客观时间线排列事件，而是把事件投射到一个以说话者当下为中心的“现实-时间-视角”坐标系里。**

## 从高频到低频

| 频率层级 | 语法现象                                                        | 特殊度          |
| ---- | ----------------------------------------------------------- | ------------ |
| 1    | 一般过去时                                                       | 低            |
| 2    | 将来表达：`will / going to`                                      | 低            |
| 3    | 现在完成时：`have done`                                           | 中低           |
| 4    | 现在进行时：`am/is/are doing`                                     | 中低           |
| 5    | 常见情态：`would / can / will / could`                           | 中低           |
| 6    | 比较级/最高级                                                     | 中低           |
| 7    | 动名词/不定式作宾语：`enjoy doing / want to do`                       | 中            |
| 8    | 定语从句：`who / which / that ...`                               | 中            |
| 9    | 被动语态：`be done`                                              | 中高，学术/新闻里更常见 |
| 10   | 第一/零条件句：`if ..., will ...` / `if ..., ...`                  | 中高           |
| 11   | 过去进行时：`was/were doing`                                      | 中高           |
| 12   | 间接引语/宾语从句时态转移                                               | 中高           |
| 13   | 过去完成时：`had done`                                            | 高            |
| 14   | 较低频情态：`may / should / might / must`                         | 高            |
| 15   | 现在完成进行时：`have been doing`                                   | 高            |
| 16   | 第二/第三条件句：`would do / would have done`                       | 很高           |
| 17   | 情态完成式：`should have done / might have done / must have done` | 很高           |
| 18   | 将来完成时：`will have done`                                      | 很高           |
| 19   | 将来进行时：`will be doing`                                       | 极高           |
| 20   | 过去完成进行时：`had been doing`                                    | 极高           |
| 21   | 混合条件句                                                       | 极高           |
| 22   | 将来完成进行时：`will have been doing`                              | 极高           |
| 23   | [[虚拟语气]]/倒装条件句：`Had I known...`                             | 极高           |
| 24   | `shall / ought to / needn't have` 等边缘情态                     | 极高           |


## 体系


[英语语法](英语语法.md)
[限定词](限定词.md)


| 语法维度 | 背后的认知含义                   |          | 像宇宙坐标里的什么  |
| ---- | ------------------------- | -------- | ---------- |
| T 时位 | 事件离“我现在说话这一刻”有多远          | 现在、过去    | 时间坐标/远近    |
| A 体  | 我从哪个角度观看事件：整体、正在展开、已经留下结果 | 一般、进行、完成 | 观察窗口       |
| M 情态 | 事件属于现实、预测、假设、愿望、义务，还是可能世界 |          | 现实性/可能世界坐标 |
| V 语态 | 我把谁放在叙述中心：行动者还是承受者        | 主动、被动    | 视角/焦点      |

所以英语谓语像是在说：

> 一个事件，不只是“发生了什么”，还必须说明：  
> 它离现在多远？我是把它看成整体、过程还是结果？它是真实、预测还是假设？我从谁的角度讲？


| 维度       | 含义                     | 常用枚举值                                                                                                                                                                          | 例子                                                     |
| -------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------ |
| **T 时位** | 事件所在时间位置               | **present 现在** / <br>**past 过去** / <br>**future 将来** / <br>**future-in-the-past 过去将来**                                                                                         | writes / wrote / will write / would write              |
| **A 体**  | 动作内部状态                 | **simple 一般体** / <br>**progressive 进行体** / <br>**perfect 完成体** / <br>**perfect progressive 完成进行体**                                                                             | writes / is writing / has written / has been writing   |
| **M 情态** | 说话人对事件的态度：能力、可能、义务、意愿等 | **none 无情态** / **can/could** / **may/might** / **must** / **shall/should** / **will/would** / **ought to** / 半情态：**have to, be going to, be able to, be supposed to, used to** | can write, must write, should write, is going to write |
| **V 语态** | 主语和动作的关系               | **active 主动** / **passive 被动**                                                                                                                                                 | writes / is written                                    |
|          |                        |                                                                                                                                                                                |                                                        |
|          |                        |                                                                                                                                                                                |                                                        |

| 维度            | 英文     | 问的问题                               | 例子                         |
| --------------- | -------- | -------------------------------------- | ---------------------------- |
| T 时位/时态形态 | Tense    | 这个谓语用现在形、过去形，还是远距形？ | works, worked, would         |
| A 体            | Aspect   | 动作内部状态是什么？一般、进行、完成？ | work, is working, has worked |
| V 语态          | Voice    | 主语是动作发出者还是承受者？           | active / passive             |
| M 情态          | Modality | 说话人态度、可能性、义务、预测？       | can, must, will, would       |
|                 |          |                                        |                              |
|                 |          |                                        |                              |
