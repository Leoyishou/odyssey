#  💡Summary  

> [!Info]
> 一句话说清楚
> 

| **模块名称**                                          | **核心定义 (What)** | **主要工作内容 (How)**                                                                                          | **核心目标 (Why)**             |
| ------------------------------------------------- | --------------- | --------------------------------------------------------------------------------------------------------- | -------------------------- |
| **1. 人力资源规划**<br><br>  <br><br>(Planning)         | HR 的顶层设计与战略导航   | • 组织架构设计<br><br>  <br><br>• 岗位分析与定编定岗<br><br>  <br><br>• 人力成本预算<br><br>  <br><br>• 人才盘点与预测                | 确保企业在正确的时间，拥有正确数量和质量的人才。   |
| **2. 招聘与配置**<br><br>  <br><br>(Recruitment)       | 企业人才的“入口”管理     | • 简历筛选与面试<br><br>  <br><br>• 招聘渠道维护<br><br>  <br><br>• 人才测评与背景调查<br><br>  <br><br>• 录用 Offer 发放           | 以合理的成本和速度，招到合适的人并放到合适的岗位上。 |
| **3. 培训与开发**<br><br>  <br><br>(Training)          | 提升员工能力的“造血”机制   | • 新员工入职培训 (Onboarding)<br><br>  <br><br>• 专业技能与业务培训<br><br>  <br><br>• 管理层领导力发展<br><br>  <br><br>• 建立培训体系 | 提升员工技能以匹配业务发展，同时增加员工粘性。    |
| **4. 绩效管理**<br><br>  <br><br>(Performance)        | 评价产出与价值分配的依据    | • 制定考核指标 (KPI/OKR)<br><br>  <br><br>• 绩效辅导与面谈<br><br>  <br><br>• 绩效打分与结果应用<br><br>  <br><br>• 改进计划 (PIP)  | 激发潜能，确保个人目标与公司战略对齐，实现优胜劣汰。 |
| **5. 薪酬福利**<br><br>  <br><br>(Compensation)       | 物质激励与留人的基础      | • 薪酬结构设计与定级<br><br>  <br><br>• 每月工资核算发放<br><br>  <br><br>• 社保公积金管理<br><br>  <br><br>• 奖金与福利方案设计           | 建立内部公平、外部有竞争力的回报体系，激励保留人才。 |
| **6. 员工关系**<br><br>  <br><br>(Employee Relations) | 法律防线与文化建设       | • 劳动合同管理 (入/离职)<br><br>  <br><br>• 劳动纠纷处理<br><br>  <br><br>• 企业文化活动与团建<br><br>  <br><br>• 员工心理疏导          | 规避法律用工风险，营造和谐积极的工作氛围。      |
