# 🪞Notes

```
  iPhone 版本指南视频制作 SOP

  一、内容准备

  1. 确定核心信息点（版本差异、购买建议）
  2. 拆分为 5-7 个场景，每个场景一个核心观点
  3. 撰写配音文案（每段 3-5 秒）

  二、配音生成

  # 使用 volc-tts skill 生成配音
  # 音色：huopo（活泼女声）
  ~/.claude/skills/volc-tts/tts.sh "文案内容" output.mp3 huopo

  # 首尾加静音填充（开头 0.8s，结尾 1s）
  ffmpeg -i input.mp3 -af "adelay=800|800,apad=pad_dur=1" output_padded.mp3

  三、视觉素材生成

  # 使用 Nanobanana (Gemini 3 Pro Image) 生成手绘风格图片
  # Prompt 模板：
  "白板手绘风格，黑色马克笔线条，简洁清晰，
  竖版 1080x1920，内容：[场景描述]"

  四、Remotion 项目搭建

  npx create-video@latest project-name
  cd project-name

  核心组件结构：
  // SlideScene - 单个场景
  const SlideScene = ({ src, audioSrc }) => {
    // Ken Burns 缩放效果
    const scale = interpolate(frame, [0, 5*fps], [1.05, 1]);
    return (
      <AbsoluteFill>
        <Audio src={staticFile(audioSrc)} />
        <Img src={staticFile(src)} style={{ transform: `scale(${scale})` }} />
      </AbsoluteFill>
    );
  };

  // TransitionSeries 串联场景
  <TransitionSeries>
    <TransitionSeries.Sequence durationInFrames={5.5*fps}>
      <SlideScene src="slide1.jpg" audioSrc="audio1.mp3" />
    </TransitionSeries.Sequence>
    <TransitionSeries.Transition presentation={fade()} />
    ...
  </TransitionSeries>

  五、音频配置
```

| 类型 | 音量 | 备注 |
| :--- | :--- | :--- |
| BGM | 10-15% | 循环播放，不抢配音 |
| TTS | 100% | 延迟 0.3s 开始 |

```
  六、渲染导出

  npx remotion render CompositionId out/video.mp4

  七、关键参数

  - 分辨率：1080x1920（竖版）
  - 帧率：30fps
  - 场景时长：根据配音长度 + 0.5s 缓冲

  ---
  耗时估算：
  - 文案 + 配音：手动
  - 图片生成：6 张约 3-5 分钟
  - 代码 + 渲染：自动化
```
