# Summary

#第一性原理 贝叶斯主义者牛逼的不是函数入参而是[[贝叶斯公式]]的函数内的计算和迭代。用证据成比例地更新信念，尊重基准率，用简单的似然比（或对数赔率）做快速、可复盘的决策，而不是凭感觉或等“绝对确定”再行动。

真正的高手，都是贝叶斯主义者，[[贝叶斯公式]]，在骰子游戏中，成功的贝叶斯主义者：
1. 不赌"是否"，而赌"概率" - 永远保持概率思维，不过度自信：保持信念的灵活性 → 经验重要，但别让它阻碍你看到新证据
2. 把信息当作资产
	1. 愿意付出成本获取信息；
	2. 别只记住支持你观点的证据 → 赢了就记住，输了就忘记 = 错误判断
	3. 考虑背景信息 → 不同赌场的作弊率不同，别只看骰子
3. 根据置信度调整行动 - 不是全进或全出，[凯利公式](凯利公式.md)
4. 理解并利用他人的偏见 - 在别人犯错时获利

核心洞察：成功不是因为他们总是对的，而是因为他们：
- 错的时候损失小（低置信度时下注少）
- 对的时候收益大（高置信度时下注多）
- 持续学习和更新（每个结果都是信息）
