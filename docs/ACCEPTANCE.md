# Odyssey：双链开发与验收清单

创建日期：2026-11-06
项目方向：基于 quiet.md 二次开发，保留原生富文本与表格编辑体验，补齐文档关联和知识导航能力。

## 验收规则

- `[ ]` 表示尚未通过验收；完成编码不等于验收通过。
- 开发完成后逐项实际操作并核对保存结果，通过后才能改为 `[x]`。
- 每个通过项须在文末验收记录中填写构建版本或提交、操作步骤、实际结果和证据位置。
- 未做、失败、阻塞的项目保持未勾选，并记录原因；不得用代码存在、编译通过代替行为验证。
- quiet.md 上游已有能力也必须在 Odyssey 构建中复测，不预先勾选。
- 本清单覆盖完整目标；P0 是基本使用闭环，P1 是完整知识导航，P2 是表格扩展。优先级不代表删减最终范围。
- 原生 Markdown 笔记库兼容属于独立工程范围。本清单中的 `[[…]]` 是交互语法，不代表已实现以 `.md` 为唯一存储。
