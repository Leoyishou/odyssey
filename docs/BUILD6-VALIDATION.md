复制导入可同时保留原生 XML，也可选择“只复制原生文档”而完全不扫描 Markdown。独立混合夹具（含 format.json、.obsidian、.git）验证 12 份 XML/UUID、索引原有字段、附件、设置、回收站保留且源文件零变化；只读权限源目录也可完成。原生 XML 与元数据归档在 `.odyssey-import/native`。

原生绝对附件和封面路径通过新库 `.odyssey-relocations.json` 重定向到本库资源，不改写 XML 字节。单测在复制后移动源库、再复制并移动第一份副本后，仍能读取独立资源。库外引用保留并报告；原生文件符号链接、损坏索引/无效格式、预览后源内容变化拒绝。

`evidence/build6-recovery-final-check.log`：99 core + 53 app、2000 fuzz seeds、指南往返通过；clippy 通过。屏外 UI 实际验证 12 XML / 0 Markdown 预览、确认复制、源/目标逐字节核对和真实新进程重开原正文/表格。见 `evidence/build6-recovery-gui/README.md`。最终签名包另用带绝对图片路径的独立夹具验证：复制后将测试源库移走，原路径不存在，新进程仍实际显示图片，且 XML/资源字节一致；证据 `asset-result.json` 与 `asset-reopen-run/independent-image.png`。原生文件选择器、真实 HOME 默认库启动、真实大型库恢复仍未验证。
