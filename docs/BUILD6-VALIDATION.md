# build6 修复验收

2026-11-06，macOS Apple Silicon。该版本修复混合库安全检测、提供复制导入，并调整工作区入口；完整 66 项仍未全部完成。

## 实际通过

- `FDL_FUZZ_SEEDS=2000 scripts/check.sh`：95 core + 51 app 测试通过，指南 XML 往返通过，clippy 零警告。既有忽略测试不计入通过数。
- 默认路径不再使用 Documents/Odyssey。混合格式标记 + Markdown/.obsidian、嵌套 Markdown、大小写别名、符号链接、非空目标与不支持格式均有拒绝测试；空目录符号链接不会被初始化。
- 复制导入先只读扫描：独立夹具包含中文文件名、嵌套目录、正文和表格别名链接、Markdown 相对链接、本地附件、代码内字面双括号、缺失目标、锚点和 YAML。2 篇 Markdown、1 层级页、3 个链接、1 附件转换成功，源内容与归档逐字节一致。新库用独立进程打开，原生正文/表格/附件及出链可见。
- 现有目标、源内容变化、源目录内目标、外部附件和无效 UTF-8 拒绝；macOS 原子发布使用 RENAME_EXCL，不替换已存在目录。混合目录界面拒绝及显式启动拒绝均确认没有源文件写入。
- 标题旁文档菜单、右上固定右栏图标、左导航独立开合、1000×800 窄窗右栏浮层正常。收起右栏没有原先 32px 占位。
- 正文及表格输入、撤销、双括号候选和 Enter 插入；右栏 280→361 调宽并重启保留。上述完整编辑回归使用本阶段前一二进制；最终二进制仅增加空符号链接保护与导入预览限高，已复跑布局/窄窗和复制导入。

## 证据与限制

本地证据：`evidence/build6-tests-final.log`、`evidence/build6-gui/README.md`、`evidence/build6-import-gui/result.json`、`reject-result.json`、导入预览/原生内容截图。应用包签名与安装包校验记录在本地 build6 manifest。

屏外 harness 的选择器通过 `pick` 模拟；其“打开新库”只记启动请求，真实新进程重开另行验证。未验证真实 IME、原生选择器、窗口材质、全量主题/快捷键回归或大型真实库导入。未对用户真实库做导入、移动或修改。

复制导入不是无损 Obsidian 兼容：插件、文档嵌入、标题/块锚点、YAML 属性、同名歧义会保留原文并报告；隐藏目录与符号链接跳过，旧 XML 留在源目录。全量文档级别名、标签页/分屏/历史、图谱及完整 66 项仍待后续实现或验收。
