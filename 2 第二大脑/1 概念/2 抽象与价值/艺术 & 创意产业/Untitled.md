# 🧩 Cues

# 🪞Notes

Behance 是 **Adobe 旗下全球领先的创意作品展示与社区平台**（2006 年创立，2012 年被 Adobe 收购），核心定位是“创意从业者的在线作品集 + 灵感引擎 + 职业连接器”，全球已有 **5000 万 + 会员**，覆盖 15 + 创意领域，是设计师、艺术家、摄影师等专业人士的必备平台。

### 一、核心定位与用户群体

- **核心价值**：为创意人提供**作品展示 → 灵感获取 → 职业机会 → 社区互动**的全链路服务，被视为设计行业的“专业社交网络”
- **主要用户**：
  - 创作者：设计师（平面/UI/工业/建筑）、插画师、摄影师、3D 艺术家、动画师、时尚设计师等
  - 需求方：企业雇主、创意总监、客户（寻找人才/灵感）
  - 学习者：设计学生、爱好者（研究优秀作品、学习创作流程）

### 三、对想逼近 RISD 水平的你，Behance 的具体用法

1.  **研究 RISD 风格项目**
    -   搜索关键词：“RISD graduate project”“RISD industrial design”“RISD graphic design”
    -   重点看：完整项目流程（调研 → 草图 → 原型 → 成品 → 说明），学习 RISD 强调的“解决问题”思维与批判性设计方法
2.  **按 RISD 标准打造作品集**
    -   每个项目必须包含：明确的问题定义、用户调研数据、至少 3 个方案迭代、最终成果与反思
    -   排版参考 RISD 毕业生作品，简洁专业，突出设计逻辑而非单纯视觉效果
3.  **获取专业反馈**
    -   发布作品后主动 @RISD 校友或行业设计师，请求针对性批评
    -   参与 Behance 设计挑战，模拟 RISD 的项目制学习环境
4.  **建立学习清单**
    -   收藏 10 个 RISD 风格优秀项目，每周拆解 1 个，分析其设计思维与表现手法
    -   按领域关注 5-10 位顶尖设计师，定期查看其作品更新，保持灵感输入

### 四、快速上手指南

1.  注册账号（可用 Adobe ID 直接登录）
2.  创建个人主页，完善简介与技能标签（如“industrial design”“user research”）
3.  发布第一个项目（建议从“解决身边小问题”的设计开始，如 RISD 学生常做的日用品优化）
4.  每天花 30 分钟浏览精选栏目，收藏优质作品并做笔记
5.  每周参与 1 次社区互动，评论或点赞他人作品，建立行业存在感
