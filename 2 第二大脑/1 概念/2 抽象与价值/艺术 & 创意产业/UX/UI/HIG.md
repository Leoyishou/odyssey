#  💡Summary  

> [!Info]
> 一句话说清楚
> 

HIG 的设计美学本质上是一种**“做减法”的艺术**。它假设“少即是多”，这在消费级内容（C端）和简单交互中非常有效。但对于生产力工具、复杂数据展示或长文本阅读，完全照搬 HIG 往往会导致信息过于稀疏。

这也是为什么很多像 Notion 这样的笔记类与效率类产品，虽然在 Apple 平台上运行，但都会发展出自己的一套更紧凑的 UI 语言，而不是盲从 HIG 的标准控件。
