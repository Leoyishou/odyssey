# Notes

种群动力学是研究生物种群数量如何随时间变化的学科，属于数学生物学的重要分支。

## 核心问题：种群数量如何变化？

研究影响种群大小的因素：
- **出生率和死亡率**
- **迁入和迁出**
- **环境承载力**
- **种间相互作用**

## 经典数学模型

### 1. 指数增长模型
- **公式**：$dN/dt = rN$
- **特点**：无限制增长（细菌早期繁殖）
- **现实**：资源有限，不可持续

### 2. Logistic增长模型
- **公式**：$dN/dt = rN(1-N/K)$
- **K**：环境承载力
- **特点**：S形增长曲线
- **应用**：单一种群在有限资源下的增长

### 3. Lotka-Volterra捕食者-猎物模型
- **描述**：狼和兔子的数量周期性波动
- **猎物多→捕食者增加→猎物减少→捕食者减少→循环**
- **应用**：生态平衡、害虫控制

### 4. 竞争模型
- **两个物种竞争同一资源**
- **结果**：共存、一方灭绝或初始条件决定

## 实际应用

**渔业管理**：
- 确定可持续捕捞量
- 避免过度捕捞导致种群崩溃

**疾病传播**：
- SIR模型（易感-感染-康复）
- 预测疫情发展
- 评估防控措施效果

**保护生物学**：
- 濒危物种保护策略
- 最小可存活种群大小
- 栖息地破碎化影响

**农业害虫控制**：
- 天敌引入时机
- 农药使用策略
- 综合防治方案

## 有趣现象

**混沌**：某些种群模型在特定参数下表现出混沌行为——微小初始差异导致完全不同的结果

**同步**：空间分离的种群可能出现数量同步波动

种群动力学展示了简单数学方程如何描述复杂的生命现象！
