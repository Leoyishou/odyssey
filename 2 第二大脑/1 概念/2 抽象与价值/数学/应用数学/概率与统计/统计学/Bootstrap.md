# 💡 Summary  

Bootstrap原意是靴子上的提襻/靴襻，有一个英语习语"pull oneself up by one's bootstraps"，意思是"靠自己的力量让自己站起来"，这其实是个物理上不可能的事（你不能拽着自己的靴襻把自己提起来），但用来比喻"**白手起家**"、"靠自己的力量"。

**白手起家**：在统计学中，Bootstrap方法就是"用样本自己产生样本"，用有限的数据靠自己产生更多信息，这和那个习语的精神很契合——看起来不可能，但确实做到了。


场景：你只有一个班50个学生的数据，要估计全校学生平均身高，想知道结果有多可靠
解决：用手头的有限数据反复"倒腾"，模拟出可能的结果范围，从而判断结论的可靠程度。

```Java

原始数据: [A, B, C, D, E]
第1次抽: [A, A, C, E, B]  → 计算结果1
第2次抽: [D, B, E, E, C]  → 计算结果2
第3次抽: [C, A, B, D, D]  → 计算结果3
...重复多次

```
