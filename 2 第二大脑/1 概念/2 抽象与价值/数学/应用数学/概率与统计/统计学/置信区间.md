问题：不告诉你这个估计有多准确，不知道误差范围

## 计算公式



```Java
# ========== 库里的数据 ==========
n = 30          # 投篮次数
made = 13       # 命中次数
p_hat = made/n  # 点估计

print(f"📊 观察数据：{n}投{made}中")
print(f"📍 点估计：{p_hat:.1%}")

# ========== 计算95%置信区间 ==========
# 方法1：正态近似法
se = np.sqrt(p_hat * (1-p_hat) / n)  # 标准误
margin = 1.96 * se                     # 误差范围
ci_lower = p_hat - margin
ci_upper = p_hat + margin

print(f"\n📏 标准误：{se:.1%}")
print(f"📏 误差范围：±{margin:.1%}")
print(f"✅ 95%置信区间：[{ci_lower:.1%}, {ci_upper:.1%}]")
```
