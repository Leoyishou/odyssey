1. 标准正态分布表、
2. χ² 分布表、
3. t 分布表、
4. F 分布表等

```Java
【两层结构】

第1层：基本分布（总体分布）
  ├─ 二项分布、泊松分布
  ├─ 正态分布、指数分布
  └─ 描述原始数据 X

第2层：抽样分布（统计量分布）⭐
  ├─ χ² 分布（方差的函数）
  ├─ t 分布（均值的函数，σ未知）
  ├─ F 分布（两个方差的比）
  └─ 从第1层推导而来
      前提：知道总体分布形式（通常是正态）
      目的：总体参数未知时的推断

关键：
  基本分布 → 研究 X（个体）
  抽样分布 → 研究统计量（样本函数）

```
