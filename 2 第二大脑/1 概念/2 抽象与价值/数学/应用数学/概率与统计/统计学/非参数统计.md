# 💡 Summary  

## **参数统计（传统方法）**

```Java
假设 → 建模 → 推断

例子：身高分析
  1. 假设：身高 X ~ N(μ, σ²)
  2. 估计参数：μ̂ = 170cm, σ̂ = 5cm
  3. 推断：基于正态分布理论
  
  依赖：必须满足正态分布假设
```

## **非参数统计（灵活方法）**

```Java
直接分析 → 推断

例子：身高分析
  1. 不假设任何分布
  2. 直接用数据本身（排序、秩）
  3. 推断：基于数据的相对大小
  
  优点：不依赖分布假设
```
