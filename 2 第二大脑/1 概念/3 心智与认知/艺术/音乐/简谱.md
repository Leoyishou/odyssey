## 3. 时值与节奏
![CleanShot 2026-02-15 at 17.40.47@2x.png|1000](https://imagehosting4picgo.oss-cn-beijing.aliyuncs.com/imagehosting/fix-dir%2Fmedia%2Fmedia_ByedcC885W%2F2026%2F02%2F15%2F17-42-58-43b7e14e0a9a30751034a6c022b82ef7-CleanShot%202026-02-15%20at%2017.40.47-2x-37ad31.png)
![CleanShot 2026-02-15 at 17.42.12@2x.png|1000](https://imagehosting4picgo.oss-cn-beijing.aliyuncs.com/imagehosting/fix-dir%2Fmedia%2Fmedia_zHktiM4eml%2F2026%2F02%2F15%2F17-43-09-5402fbdda319fa72444380760421c925-CleanShot%202026-02-15%20at%2017.42.12-2x-ab95d0.png)

| **符号**             | **名称**   | **时值（拍数）** | **你的图片示例**   |
| -------------------- | ---------- | ---------------- | ------------------ |
| **`5 - - -`**        | 全音符     | 4 拍             | —                  |
| **`5 -`**            | 二分音符   | 2 拍             | `1 - -` 中的一部分 |
| **`5`**              | 四分音符   | 1 拍             | 图中的单纯数字 `5` |
| **`5`** (带下划线)   | 八分音符   | 0.5 拍           | 带有单横线的音符   |
| **`5`** (带双下划线) | 十六分音符 | 0.25 拍          | 带有双横线的音符   |
| **`5·`**             | 附点音符   | 增加原时值的一半 | 你算出的 `1.5` 拍  |
| **`-`**              | 增时线     | 增加一拍         | 绿框里的短横线     |

| 要素                 |         | 作用                       | 记法             |
| ------------------ | ------- | ------------------------ | -------------- |
| **空白数字**           |         | 基本时值 = 1 拍（在 4/4 中为四分音符） | “5”            |
| **附点**             |         | 时值 ×1.5                  | “`3.`”         |
|                    |         |                          |                |
| **尾巴（连横弧）**        |         | 连音（tie/slur）或长横线跨小节      | “3–3” 或 “3 —┓” |
| **连线/括弧**          |         | 指定连奏、滑音、倚音               | “(6 7 1)”      |
| 延音线 (Tie)          | **横线–** | 不要重唱/重弹、时值合并             | “5–”           |
| **“-”** 被称为**增时线** |         | 它代表**增加一个四分音符的时值**。      |                |

- **没有横线**：如 `5`
    - 这是 **四分音符**，代表 **一拍**。它是时长的基本单位。
- **一条横线**：如 `<u>5 5</u>`
    - 这是 **八分音符**，每条横线把时值减半。它的时长是 **半拍**。
    - （两个八分音符加起来等于一个四分音符的时长）。
- **两条横线**：如 `<u>5 5</u>`
    - 这是 **十六分音符**，两条横线把时值再次减半。它的时长是 **四分之一拍**。
    - （四个十六分音符加起来等于一个四分音符的时长）。


## 4. 分段与结构

- **`|` (小节线)**：分隔音符的垂直线。
    
- **`||` (终止线)**：乐曲结束。
    
- **`:||` (右反复记号)**：跳回前面的左反复记号处重新开始。
    
- **`0` (休止符)**：在这一拍停顿，不发声。



| 要素       | 作用                                               | 记法                |
| -------- | ------------------------------------------------ | ----------------- |
| 小节线      | 你可以把小节想象成一个固定大小的盒子，里面的音符可以切得很碎，但最后拼起来必须正好填满这个盒子。 | 分隔拍子              |
| **复线     |                                                  | **                |
| **反复记号:  |                                                  | :**               |
| **跳跃指令** | Dal Segno，Coda 等                                 | 常用文字提示“D.S.”、“𝄌” |

### ✍️ 一眼看懂的示例片段

```text
1=C   4/4   ♩=80  Andante
|  5 .    5  |  6  -  6 | 7 .   6  | 5   -  - ||
我 爱 你 的   眼 神
  C       G     Am      F
```

- **5.** = 数字 5 加附点 → 1.5 拍
    
- **6 -** = 延长线 → 多 1 拍
    
- 竖线 `|` 分小节，`||` 表段落结束
    
- 上方和弦：C → G → Am → F
    
- 下方歌词与数字逐字对齐
