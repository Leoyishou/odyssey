# 🪞Notes
“白皮书”就是一种**正式、系统地说明某个问题、政策、技术、行业或方案的文档**。

常见意思有两类：

|场景|白皮书是什么意思|例子|
|---|---|---|
|政府/机构|对某个政策、立场、事实情况的正式说明|《中国的能源转型白皮书》|
|企业/行业|对某个行业趋势、技术方案、产品能力的深度介绍|《AI Agent 行业白皮书》《云安全技术白皮书》|

它通常有几个特点：

- **比较正式**：不是随便写的文章，更像官方说明或专业报告。
- **有完整结构**：背景、问题、现状、数据、分析、方案、结论。
- **带有立场或方案**：不只是介绍信息，往往想说明“我们怎么看”“我们怎么做”“这个方向为什么重要”。
- **用于建立权威感**：政府用来公布立场，企业用来展示专业性和影响力。

简单说：  
**白皮书 = 用比较正式、系统、权威的方式，把一个问题讲清楚的报告。**
