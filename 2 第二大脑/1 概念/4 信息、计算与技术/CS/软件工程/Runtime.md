#  💡Summary  

> [!Info]
> 一句话说清楚
> 

|类比对象|在个人 PC 日常里的对应物|
|---|---|
|程序 / 逻辑|你的工作流、习惯、脚本、快捷键、打开哪些软件、怎么处理文件|
|Runtime|让这些操作能顺畅跑起来的电脑环境：系统、软件、CLI、浏览器、配置、权限、环境变量、本地服务|
|State / 数据|文件、笔记、历史记录、缓存、账号登录态、数据库、聊天记录、项目目录|

所以“换新电脑刚开始做的事儿就是重建 runtime”这个说法很贴切。

但要注意一点：新电脑不是只重建 runtime，也常常同时迁移 `state`。比如：

|动作|更像什么|
|---|---|
|安装 Homebrew、Python、Node、Chrome、WPS、Cursor|重建 runtime|
|配置 PATH、代理、SSH key、API key、dotfiles|重建 runtime|
|登录 Apple、飞书、GitHub、Notion、浏览器账号|runtime + 权限上下文|
|拷贝 Obsidian、项目代码、Excel、数据库|迁移 state / 数据|
|恢复浏览器历史、插件配置、快捷指令|runtime + state|
|重新养成窗口布局、快捷键、自动化习惯|恢复个人操作系统的执行环境|

一句话：  
**你的 PC runtime = 操作系统 + 已安装工具 + 配置 + 权限 + 本地服务 + 数据入口，支撑你的日常工作流持续执行。**

所以你其实是在维护一个“个人操作系统的 runtime”。换电脑、重装系统、迁移工作区，本质上就是 runtime reconstruction。
