# 🧩 Cues



# 🪞Notes
**不是平行概念**，它们处于不同的层级:

## HIG / Material Design

**完整的设计系统 (Design System)**

- 设计哲学 + 组件库 + 交互规范 + 实现代码
- 涵盖布局、动效、可访问性、响应式等全方位
- 目标是平台内的**一致性和可用性**
- Apple/Google 官方维护，有权威性

## Neo-Brutalism

**视觉风格 (Visual Style/Aesthetic)**

- 主要定义"长什么样"
- 没有系统性的交互标准
- 更像是设计师的艺术选择
- 社区驱动的趋势，而非标准

---

**更准确的类比:**

```
设计系统          Neo-Brutalism 可以叠加在上面
├─ HIG           → iOS app 用新粗野风格皮肤
├─ Material      → Android app 用粗黑边框
└─ Fluent        → Windows app 也能粗野化
```

就像你可以做一个"Material Design 规范但视觉采用 Neo-Brutalism"的 app - 底层交互遵循 Material，但视觉上用粗黑边框+扁平色块。

**简单说:** HIG/Material 是"设计宪法"，Neo-Brutalism 是"穿衣风格" 🎨
