# Notes
背景：MXNet 是一个开源深度学习框架，2016 年被 Amazon 选为 AWS 的官方深度学习框架，AWS 提供了对它的深度支持（Deep Learning AMI、SageMaker 集成等）。
	•	定位：和 PyTorch、TensorFlow 一样，MXNet 也支持符号式和命令式编程，兼顾灵活性和高性能。
	•	现状：不过近年来，PyTorch 的社区和生态已经远远超过 MXNet，Amazon 也在不少地方转向支持 PyTorch。
