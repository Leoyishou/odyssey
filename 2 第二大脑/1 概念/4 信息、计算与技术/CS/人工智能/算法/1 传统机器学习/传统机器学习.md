# Summary💡


传统机器学习不会"看懂"文本。传统[[机器学习ML@]]模型的本质：传统模型（逻辑回归、随机森林、SVM等）只能处理数字，而且是通过简单的数学运算。

```Java
# 逻辑回归的本质：线性组合 + sigmoid
prediction = sigmoid(w1x1 + w2x2 + w3x3 + ... + b)

# 随机森林的本质：一堆 if-else 判断树
if x1 > 5:
    if x2 < 10:
        return 1
    else:
        return 0
```
