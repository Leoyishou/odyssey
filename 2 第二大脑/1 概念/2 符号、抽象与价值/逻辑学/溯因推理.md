# 哲学地位的确立

## 1. [[皮尔士]]（C.S. Peirce）的贡献

他在19世纪末首次将溯因推理（他称为"假设推理"）提升到与演绎、归纳并列的地位，论证了：
- 演绎展开知识
- 归纳评估知识
- 溯因创造知识

## 2. **不可还原性**
溯因不能被简化为演绎或归纳：
- 不是演绎：因为结论不是必然的
- 不是归纳：因为不是从多个实例概括，而是为单一现象寻找解释

## 3. **推理的完整性**
三种推理形成了人类认知的完整循环：

```Java
溯因（产生假说）→ 演绎（推导预测）→ 归纳（验证假说）
```

# 形式化的区别

用逻辑形式表示：

**演绎**：

```Java
P → Q
P
------
∴ Q
```

**归纳**：

```Java
Q₁, Q₂, Q₃, ..., Qₙ (都具有属性P)
------------------------
∴ 所有Q都有属性P（概率性）
```

**溯因**：

```Java
Q
P → Q
------
∴ P（作为最佳解释）
```

注意：溯因推理在形式上类似"肯定后件谬误"，但它不追求必然性，而是追求最佳解释。
