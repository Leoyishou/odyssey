# Summary

回溯是种写起来简洁的多层for*暴力穷举*搜索，再配合一些剪枝优化。
为啥能写起来简洁，因为用了递归

对于要穷举的树结构，backtrack函数是纵向逻辑，for循环是横向逻辑，最终实现对树结构的穷举

```java
void backtracking(参数) {
	// 终止条件
    if () {
        存放结果;
        return;
    }
	
	// 处理逻辑
    for (选择：本层集合中元素（树中节点孩子的数量就是集合的大小）) {
        处理节点;
        backtracking(路径，选择列表); // 递归
        回溯，撤销处理结果
    }
}
```
