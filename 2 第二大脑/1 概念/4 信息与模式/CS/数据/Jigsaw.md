# 💡 Summary  

**Jigsaw** 是 Google 旗下的一个研究机构（属于 Alphabet），与 Google 共同创立了 **Conversation AI** 团队 [Sparknlp](https://sparknlp.org/2021/01/21/multiclassifierdl_use_toxic_en.html)

Jigsaw 是 Google 的子公司 [Medium](https://medium.com/@cyrilmarzook/google-jigsaw-toxic-comment-classification-727e38e988a1)，专注于利用技术解决在线安全和有害内容问题。

---

## 主要产品：Perspective API

Jigsaw 开发了 **Perspective API**，这是一个使用机器学习来减少在线毒性内容的工具，可以检测评论中的毒性（toxicity）[Sparknlp](https://sparknlp.org/2021/01/21/multiclassifierdl_use_toxic_en.html)

# Jigsaw 在 NLP 领域的影响

## 最著名的贡献：Toxic Comment Classification Challenge

Jigsaw 在 Kaggle 上举办了多个**有毒评论分类挑战赛**（Toxic Comment Classification Challenge）[Kaggle](https://www.kaggle.com/competitions/jigsaw-toxic-comment-classification-challenge)[Medium](https://medium.com/@cyrilmarzook/google-jigsaw-toxic-comment-classification-727e38e988a1)
