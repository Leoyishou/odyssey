# Summary


`.whl`
- **Wheel (whl)** 是 Python 官方定义的一种 **打包格式**，全名是 **Python Wheel Package**。
- 它本质上是一个 **已经编译好的二进制分发包**，比传统的 `.tar.gz` 源码包安装更快，因为不用在本地重新编译 C/CUDA 扩展。
- 安装时，`pip install xxx.whl` 会直接把 wheel 文件解压并拷贝到 site-packages 里。
