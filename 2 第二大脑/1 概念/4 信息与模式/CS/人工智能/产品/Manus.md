> [!info]
> 意念 与（LLM+图灵机） 的桥梁
> 




| **Connector 名称**          | **简介与热度证据 (Evidence Based)**                                                                |
| ------------------------- | ------------------------------------------------------------------------------------------- |
| **1. Gmail**              | **【核心基石】** 被官方 API 文档和 MCP 文档双重列为“Popular/热门选项”。作为 Agent 对外沟通和接收信息的第一入口，属于无需解释的 Tier 0 级组件。 |
| **2. Google Calendar**    | **【时间管理】** 同样获双重文档“热门”认证。它是 Agent 执行日程规划、会议预约等助理类任务的必要依赖。                                   |
| **3. Notion**             | **【知识大脑】** 官方不仅将其列为 API 热门，还投入资源专门撰写了“用户故事集”，暗示其作为非结构化数据（笔记/文档）核心存储库的战略地位极高。                |
| **4. Google Drive**       | **【文件枢纽】** 官方博客专门撰文介绍，强调解决“文件搬运”痛点，并在 Project Connectors 中被标记为“必连工具”。是 Agent 读取/生成文档的物理硬盘。  |
| **5. Slack**              | **【协作总线】** 2025 年底官方博文重点推介，定位从单纯的聊天升级为“可查询知识库”和“协作回写终端”，在团队场景中优先级极高。                        |
| **6. GitHub**             | **【研发标准】** 官方将其列入“Essential Apps”并在帮助中心作为 Issue 管理和 Release Notes 生成的典型落地案例，是技术类 Agent 的标配。 |
| **7. Stripe**             | **【支付结算】** MCP 文档热门选项，且有专门博文支持。常用于构建自动化账单、订阅管理等涉及资金流的商业化 Agent 工作流。                         |
| **8. HubSpot**            | **【客户关系】** MCP 文档热门选项，常与 Gmail/Notion 组合出现。标志着 Sales/Marketing 场景是 Manus 重点发力的垂直领域。         |
| **9. Hugging Face**       | **【模型扩展】** MCP 文档热门选项，归类于 Development。这表明 Manus 鼓励开发者通过 Connector 调用外部模型能力，而非仅依赖内部模型。       |
| **10. Linear / Postgres** | **【长尾基建】** 包含 Linear、Supabase 等工具。虽在帮助中心作为“典型实现”提及，但在主站营销上略弱于前序产品，属于开发者和垂直项目管理者的刚需工具。       |
