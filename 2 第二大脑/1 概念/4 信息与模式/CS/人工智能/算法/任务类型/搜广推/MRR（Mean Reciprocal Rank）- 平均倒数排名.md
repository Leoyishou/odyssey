# 💡 Summary  

MRR（Mean Reciprocal Rank）- 平均倒数排名

核心问题："第一个正确答案出现在第几位？"


## 适用场景
```Java
✅ 适合 MRR：
- 问答系统："北京的首都是哪？" → 只有1个正确答案
- 导航查询："淘宝官网" → 用户只想要第一个链接
- 实体搜索："苹果公司CEO" → 明确的事实

❌ 不适合 MRR：
- 信息搜索："成都旅游攻略" → 可能有很多好答案
- 推荐系统：用户可能对多个结果都感兴趣
```

# 🧩 Cues



# 🪞Notes

假设你在搜索引擎搜"北京天气"，系统返回10个结果：
位置1: 上海天气 ❌
位置2: 广州天气 ❌  
位置3: 北京天气 ✅ ← 第一个正确答案在第3位
位置4:...

**倒数排名 RR（Reciprocal Rank）= 1/3 = 0.333**

如果第一个正确答案在第1位，RR = 1/1 = 1.0（完美）
如果第一个正确答案在第10位，RR = 1/10 = 0.1（很差）
如果10个结果都错，RR = 0



## 计算公式
```Java
RR (单次查询) = 1 / rank_of_first_correct_answer

MRR (平均) = (RR₁ + RR₂ + ... + RRₙ) / n
```

---

## 实际例子

用户做了3次搜索：

### 查询1："成都3天游"
```Java
结果：
1. 成都7天游 ❌
2. 成都3天游 ✅ ← 第一个正确答案在第2位
3. 成都周边游 ❌

RR₁ = 1/2 = 0.5
```

### 查询2："北京故宫门票"
```Java
结果：
1. 北京故宫门票 ✅ ← 第一个正确答案在第1位
2. 北京天坛门票 ❌
3. ...

RR₂ = 1/1 = 1.0
```

### 查询3："杭州西湖"
```Java
结果：
1. 杭州美食 ❌
2. 杭州购物 ❌
3. 杭州交通 ❌
4. 杭州西湖 ✅ ← 第一个正确答案在第4位
5. ...

RR₃ = 1/4 = 0.25
```

### 计算 MRR
```Java
MRR = (0.5 + 1.0 + 0.25) / 3 = 0.583
```

---

## MRR 的含义

| MRR 分数 | 含义 | 用户体验 |
|---------|------|---------|
| **1.0** | 每次第一个结果都对 | 完美 ⭐⭐⭐⭐⭐ |
| **0.8-1.0** | 通常第1-2个结果就对 | 优秀 ⭐⭐⭐⭐ |
| **0.5-0.8** | 平均在前3个结果能找到 | 良好 ⭐⭐⭐ |
| **0.3-0.5** | 平均要翻到第4-5个 | 一般 ⭐⭐ |
| **< 0.3** | 答案通常很靠后 | 差 ⭐ |

---

## MRR 的特点

### ✅ 优点
1. **简单直观**：关注"第一个对的在哪"
2. **符合用户习惯**：用户通常只点击前几个结果
3. **适合单答案场景**：问答系统、导航查询

### ❌ 缺点
1. **只看第一个**：后面的正确答案都被忽略
2. **二元判断**：要么对(1)要么错(0)，没有"部分正确"
