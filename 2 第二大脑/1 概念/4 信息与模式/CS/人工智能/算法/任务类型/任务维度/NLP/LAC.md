# LAC 详细介绍

LAC (Lexical Analysis of Chinese) 是**百度开源的中文词法分析工具**，集成了分词、词性标注和命名实体识别功能。

## **1. 基本信息**

- **开发者**: 百度 NLP 团队
- **开源时间**: 2018年
- **GitHub**: [https://github.com/baidu/lac](https://github.com/baidu/lac)
- **License**: Apache 2.0
- **支持语言**: Python, C++, Java
- **模型基础**: 基于 [[BiGRU]]-CRF 神经网络
