# 🧩 Summary  

## 重复性惩罚 (Repetition Penalty)

**通俗理解:** 已经出现过的词,下次生成时**降低它的概率**。

**实现:**

```Java
新概率 = 原概率 / (penalty ** 出现次数)
```

**例子:**

- 原始可能生成: "我喜欢猫,我喜欢猫,我喜欢猫..."
- 加惩罚后: "我喜欢猫,它很可爱,性格温顺..."

**参数:** `repetition_penalty=1.2` (>1 惩罚重复,=1 不惩罚)
