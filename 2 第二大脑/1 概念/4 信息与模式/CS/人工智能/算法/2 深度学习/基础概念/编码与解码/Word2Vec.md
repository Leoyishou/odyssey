# 本质是Embedding

目标：[[embedding]]的一种实现方式

传统方法（one-hot编码）：
```Java
猫 = [1, 0, 0, 0, 0, ...]  ← 离散、独立
狗 = [0, 1, 0, 0, 0, ...]  ← 看不出任何关系
```

```Java
猫 = [0.2, -0.5, 0.8, 0.3, ...]  ← 连续、稠密

```

# 两种方法

- **两个算法**：continuous bag-of-words（[[CBOW]]）和 [[skip-gram]]。CBOW 是根据中心词周围的上下文单词来预测该词的词向量。skip-gram 则相反，是根据中心词预测周围上下文的词的概率分布。

|特性|CBOW|Skip-gram|
|---|---|---|
|**预测方向**|上下文 → 中心词|中心词 → 上下文|
|**训练样本数**|少（一个窗口一个样本）|多（一个窗口多个样本）|
|**训练速度**|快|慢|
|**效果**|对高频词效果好|对低频词效果好|
|**数据量需求**|适合小数据集|适合大数据集|
|**类比任务**|完形填空|看词联想/造句|

---




- **两个训练方法**：negative sampling 和 hierarchical softmax。Negative sampling 通过抽取负样本来定义目标，hierarchical softmax 通过使用一个有效的树结构来计算所有词的概率来定义目标。
