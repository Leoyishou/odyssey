# 💡 Summary  

Jaccard 相似度

衡量两个集合的重叠程度
公式：交集大小 / 并集大小
例子：

集合A = {1,2,3,4}
集合B = {3,4,5,6}
交集 = {3,4}，并集 = {1,2,3,4,5,6}
Jaccard = $2/6 = 0.33$
