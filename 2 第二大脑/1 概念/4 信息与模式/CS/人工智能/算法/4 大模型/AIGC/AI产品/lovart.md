# 💡 Summary  

## 批量生成

网站内支持一 [Lovart AI](https://www.lovart.io/)次生成最多 40 张图像，适合批量创建表情包、T恤、手机壳等产品设计。

## API 状态

API 目前还在开发中（"we are actively developing a comprehensive Lovart API"），尚未正式开放。 [Lovart](https://lovart.info/lovart-ai-code)计划中的 API 功能包括：

- AI 图像分析（自动标签、对象识别、配色提取）
- 参数化设计生成
- 内容建议引擎

## 现有集成

目前支持 Figma、Photoshop 等工具的集成，为专业设计师提供无缝工作流。
