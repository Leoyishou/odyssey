## ## 一、剪辑技巧

| 技巧类别 | 技巧名称 | 说明 | 使用场景建议 | 备注 |
|---|---|---|---|---|
| 音画剪辑 | J-cut | 声音先于画面进入 | 对话场景自然过渡、预告下个场景、制造悬念 | 让观众"听到"下一个场景 |
| | L-cut | 画面先切，声音延续 | 反应镜头、情绪延续、对话更流畅 | 保持音频连续性 |
| | Split Edit | J-cut 和 L-cut 组合 | 复杂对话场景、多人交谈、纪录片访谈 | 最自然的剪辑方式 |
| | Match Cut | 动作/形状匹配剪辑 | 时空转换、隐喻过渡、创意转场 | 《2001太空漫游》骨头变飞船 |
| | Cross Cut | 交叉剪辑 | 平行动作、制造紧张感、最后一分钟营救 | 动作片常用 |
| | Cut on Action | 动作中剪切 | 打斗场景、体育赛事、舞蹈表演 | 在动作30-40%处剪切最流畅 |
| | Cutaway | 切出镜头 | 掩盖剪辑点、展示反应、时间省略 | B-roll 的主要用法 |
| | Insert | 插入特写 | 强调细节、提供信息、制造节奏变化 | 手部特写、表情特写 |
| | Jump Cut | 跳切 | 时间流逝、焦虑感、YouTube vlog 风格 | 故意打破连续性 |
| | Smash Cut | 猛切 | 突然惊醒、对比强烈、喜剧效果 | 从安静到吵闹场景 |
