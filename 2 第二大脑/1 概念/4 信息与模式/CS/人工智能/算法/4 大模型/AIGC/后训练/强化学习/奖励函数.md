### 2. **真实的奖励函数**

在实际应用中，有几种不同的奖励函数：

#### A. **R1-Zero奖励函数**（数学问题）
```python

def question_only_reward_fn(response, ground_truth, fast=True):
```

### 3. **奖励函数的组成部分**

每个奖励函数都返回一个字典，包含三个部分：

```python
{
    "reward": float,        # 总奖励（主要用于训练）
    "format_reward": float, # 格式奖励（是否按正确格式回答）
    "answer_reward": float  # 答案奖励（答案是否正确）
}
```

### 4. **奖励函数的工作原理**

#### 输入
- `response`: 模型的回答
- `ground_truth`: 标准答案

#### 输出
- 奖励分数（0-1之间）

#### 评估标准
1. **格式正确性**：是否按照要求的格式回答
2. **答案正确性**：答案是否与标准答案匹配
3. **总奖励**：综合考虑格式和答案

### 5. **生活中的类比**

就像**老师批改作业**：

1. **格式分**：字迹工整、格式规范（format_reward）
2. **答案分**：答案是否正确（answer_reward）
3. **总分**：综合评分（reward）

### 6. **经典问题变体**

这实际上是**自动评分系统**的经典问题：
- **考试评分**：自动批改选择题
- **作文评分**：评估写作质量
- **代码评分**：检查程序正确性
- **对话评估**：评价对话质量

**核心思想**：通过自动化的奖励函数，为强化学习提供训练信号，让模型学会生成更好的回答。
