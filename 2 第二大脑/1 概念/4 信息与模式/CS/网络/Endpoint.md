# Summary

- **Endpoint** = “接口说明书（抽象定义）”
- **Request** = “发出去的一次 HTTP 请求（具体执行）”

# Notes

- **定义层面**：
    Endpoint 就是 **接口的定义**。它描述了这个 API 的基本信息：
    - URL（地址，比如 `/user/login`）
    - 方法（GET / POST / PUT / DELETE）
    - 请求参数（query/body/header）
    - 响应结构（返回的 JSON/Schema）
- **类比**：就像写一份接口说明书，告诉别人“有一个接口可以用来做登录”。
