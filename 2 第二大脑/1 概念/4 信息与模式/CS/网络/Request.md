# Summary

- **调用层面**：
    Request 是一个 **具体的请求**，即你拿着 Endpoint 定义出来的接口去 **实际发一次请求**。
    
    - 可以带具体的参数（比如 username=tom, password=123456）
        
    - 可以测试响应结果（比如返回 token）
        
- **类比**：就像你拿着说明书上的接口地址，真的去点了一下“登录”按钮，并且把用户名密码填进去发出去。
