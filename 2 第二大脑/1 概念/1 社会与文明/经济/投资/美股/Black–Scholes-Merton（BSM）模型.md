# Summary


交易员用这些方程计算：

- **Delta**：股价涨1元，期权涨多少
- **Gamma**：Delta变化的速度
- **Theta**：时间流逝让期权贬值多快
- **Vega**：波动率变化的影响

这些都是微分方程的解或者导数！

所以说，**现代期权交易本质上就是在交易微分方程的解**。

# Notes

有！期权定价和微分方程有**极其密切**的关系。

## 核心联系：Black-Scholes方程

期权定价最著名的模型就是用**偏微分方程**推导出来的。这个方程描述了：

**期权价格是怎么随时间和股价变化的**

就像咖啡变凉的速度取决于温差，期权价格的变化速度取决于：

- 股票现在的价格
- 距离到期还有多久
- 股价的波动程度
- 无风险利率

## 为什么需要微分方程？

因为期权的价值在**不断变化**：

1. **时间在流逝** → 期权在贬值（时间价值衰减）
2. **股价在波动** → 期权价值随之起伏
3. **波动率在变** → 影响期权的"可能性"价值

这些变化相互影响，形成了复杂的动态系统。

## 通俗理解

想象期权就像**保险**：

- 你买了一份"30天内以100元买入股票"的权利
- 如果股票现在95元 → 这份权利价值较低
- 如果股票涨到105元 → 这份权利变得值钱
- 但每过一天 → 权利的时间价值在减少

微分方程就是把这些"如果...就..."的关系，精确地用数学表达出来。
