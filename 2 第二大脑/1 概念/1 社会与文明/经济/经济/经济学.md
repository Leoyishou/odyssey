# 经济学学科体系

| 一级学科         | 二级学科          | 三级分支    | 主要研究内容              | 典型应用        |
| ------------ | ------------- | ------- | ------------------- | ----------- |
| **理论经济学**    | [[微观经济学]]     | 消费者理论   | 效用理论、需求函数、消费者剩余     | 市场需求分析、定价策略 |
|              |               | 生产者理论   | 生产函数、成本理论、利润最大化     | 企业决策、成本控制   |
|              |               | 市场结构理论  | 完全竞争、垄断、寡头、垄断竞争     | 反垄断政策、产业组织  |
|              |               | 一般均衡理论  | 瓦尔拉斯均衡、帕累托效率        | 市场效率分析      |
|              |               | 福利经济学   | 社会福利函数、次优理论         | 政策评估、收入分配   |
|              |               | 信息经济学   | 不对称信息、逆向选择、道德风险     | 保险设计、金融监管   |
|              | [[宏观经济学]]     | 经济增长理论  | 索洛模型、内生增长、增长核算      | 发展政策、长期规划   |
|              |               | 经济周期理论  | 真实周期、凯恩斯周期、金融周期     | 经济预测、稳定政策   |
|              |               | 货币理论    | 货币需求、货币供给、通货膨胀      | 货币政策、央行决策   |
|              |               | 失业理论    | 自然失业率、工资粘性、搜寻理论     | 就业政策、劳动市场   |
|              |               | 开放经济理论  | 汇率决定、国际收支、蒙代尔-弗莱明模型 | 汇率政策、资本管制   |
|              | **计量经济学**     | 经典计量    | OLS、工具变量、面板数据       | 实证研究、预测     |
|              |               | 时间序列分析  | ARIMA、VAR、协整        | 经济预测、动态分析   |
|              |               | 微观计量    | 离散选择、持续时间模型         | 个体行为分析      |
|              |               | 因果推断    | RCT、DID、RDD、合成控制    | 政策效果评估      |
|              |               | 机器学习方法  | 预测模型、文本分析、高维数据      | 大数据经济分析     |
|              | **数理经济学**     | 最优化理论   | 线性规划、非线性优化、动态规划     | 资源配置、决策分析   |
|              |               | 博弈论     | 纳什均衡、子博弈精炼、机制设计     | 拍卖设计、策略分析   |
|              |               | 数学金融    | 随机过程、偏微分方程、测度论      | 衍生品定价、风险管理  |
|              | [[政治经济学]]     | 古典政治经济学 | 价值理论、剩余价值、资本积累      | 经济制度分析      |
|              |               | 新政治经济学  | 公共选择、寻租理论、宪政经济学     | 制度设计、腐败研究   |
|              |               | 比较经济体制  | 市场经济、计划经济、混合经济      | 经济改革、转型研究   |
|              | **经济史与经济思想史** | 经济史     | 工业革命、大萧条、经济奇迹       | 历史经验、路径依赖   |
|              |               | 经济思想史   | 重商主义、古典学派、凯恩斯革命     | 理论演进、范式转换   |
| **应用经济学**    | **金融学**       | 公司金融    | 资本结构、股利政策、并购重组      | 企业财务决策      |
|              |               | 投资学     | 资产定价、投资组合、市场有效性     | 投资策略、基金管理   |
|              |               | 金融市场    | 股票、债券、衍生品、外汇市场      | 市场交易、风险对冲   |
|              |               | 金融机构    | 银行、保险、投资银行、基金       | 金融中介、风险管理   |
|              |               | 金融科技    | 数字货币、区块链、智能投顾       | 金融创新、普惠金融   |
|              | **产业经济学**     | 产业组织    | 市场集中度、进入壁垒、纵向一体化    | 反垄断、产业政策    |
|              |               | 规制经济学   | 自然垄断、价格规制、激励规制      | 公用事业监管      |
|              |               | 网络经济学   | 网络效应、平台经济、双边市场      | 互联网经济、平台治理  |
|              |               | 创新经济学   | R&D、专利、技术扩散         | 创新政策、知识产权   |
|              | **劳动经济学**     | 劳动供求    | 工资决定、人力资本、劳动参与      | 就业政策、工资谈判   |
|              |               | 人力资本    | 教育经济学、培训、技能匹配       | 教育投资、职业培训   |
|              |               | 劳动市场歧视  | 性别差距、种族歧视、统计性歧视     | 反歧视政策       |
|              |               | 劳动关系    | 工会、集体谈判、劳动法规        | 劳资协调、社会对话   |
|              | **公共经济学**     | 公共财政    | 税收理论、最优税制、税收归宿      | 税制改革、财政政策   |
|              |               | 公共支出    | 公共品、外部性、成本效益分析      | 预算分配、项目评估   |
|              |               | 社会保障    | 养老、医疗、失业保险          | 福利制度设计      |
|              |               | 财政联邦主义  | 中央与地方、转移支付、税收竞争     | 财政分权、区域协调   |
|              | **国际经济学**     | 国际贸易    | 比较优势、贸易政策、贸易协定      | 贸易谈判、产业保护   |
|              |               | 国际金融    | 汇率理论、国际资本流动、金融危机    | 汇率制度、资本管制   |
|              |               | 跨国公司    | FDI、全球价值链、转移定价      | 投资政策、税收筹划   |
|              |               | 经济一体化   | 关税同盟、共同市场、经济联盟      | 区域合作、一体化    |
| **专门经济学**    | **发展经济学**     | 经济发展理论  | 二元经济、贫困陷阱、中等收入陷阱    | 发展战略、减贫政策   |
|              |               | 结构转型    | 工业化、城市化、现代化         | 产业升级、城市规划   |
|              |               | 制度与发展   | 产权、治理、腐败            | 制度改革、治理改善   |
|              |               | 可持续发展   | 资源约束、代际公平、绿色增长      | 可持续发展目标     |
|              | **区域经济学**     | 空间经济学   | 集聚经济、中心-外围、新经济地理    | 城市规划、区域政策   |
|              |               | 城市经济学   | 土地利用、住房市场、城市交通      | 城市管理、房地产    |
|              |               | 区域发展    | 区域差距、增长极、产业集群       | 区域规划、协调发展   |
|              | **环境经济学**     | 环境估值    | 外部性内部化、环境成本效益       | 环境政策、碳定价    |
|              |               | 资源经济学   | 可耗竭资源、可再生资源、公地悲剧    | 资源管理、渔业配额   |
|              |               | 气候经济学   | 碳税、排放权交易、气候损害       | 气候政策、碳中和    |
|              |               | 循环经济    | 废物利用、生命周期分析         | 绿色转型、清洁生产   |
| **行为与实验经济学** | **行为经济学**     | 判断与决策   | 启发式、偏见、框架效应         | 行为干预、助推     |
|              |               | 跨期选择    | 时间偏好、自我控制、承诺机制      | 储蓄促进、养老规划   |
|              |               | 社会偏好    | 公平、互惠、利他主义          | 激励设计、慈善     |
|              |               | 行为金融    | 过度自信、羊群效应、处置效应      | 投资者教育、市场监管  |
|              | **实验经济学**     | 实验室实验   | 市场实验、公共品实验、拍卖实验     | 机制检验、政策模拟   |
|              |               | 田野实验    | RCT、自然实验、准实验        | 政策评估、项目效果   |
|              |               | 神经经济学   | fMRI、脑电图、生理测量       | 决策机制、情绪影响   |
| **新兴交叉领域**   | **数字经济学**     | 平台经济    | 网络效应、算法定价、数据垄断      | 平台监管、反垄断    |
|              |               | 共享经济    | 闲置资源、P2P、信任机制       | 新业态监管       |
|              |               | 数据经济    | 数据要素、隐私保护、数据交易      | 数据治理、产权界定   |
|              | **复杂经济学**     | 基于主体建模  | ABM、网络模型、涌现现象       | 系统性风险、传染    |
|              |               | 经济物理学   | 统计物理、幂律分布、相变        | 金融市场、财富分布   |
|              |               | 演化经济学   | 创新演化、路径依赖、制度演化      | 技术变迁、产业演进   |
|              | **文化经济学**     | 文化产业    | 创意经济、版权经济、文化贸易      | 文化政策、产业发展   |
|              |               | 文化与经济发展 | 价值观、信任、社会资本         | 发展差异、制度效率   |
|              | **健康经济学**     | 医疗经济学   | 医疗保险、医疗服务、药物经济学     | 医改政策、医保设计   |
|              |               | 健康行为    | 预防、生活方式、健康不平等       | 公共卫生、健康促进   |
