理解激励机制、边际成本、供需关系、代理人理论

如果你没有上过任何经济学课程，那么我首先来做一个超短的评论：经济学是这样的学科之一，刚开始学的时候轰轰烈烈，有许多有用的、言之有理的理论和可以在真实世界中得到证明的事实，等等；但是，再学下去就每况愈下，有用的东西就不多了。经济学一开始那个有用的部分正是微观经济学，它是商业领域所有重要理论的基础。跟在微观经济学后面的东西就不行了。你接下来学的是宏观经济学，如果你愿意，尽管跳过去，也不会有什么损失。

| **激励机制**<br><br>  <br><br>(Incentives)              | **指挥棒**<br><br>  <br><br>人不做你希望他做的事，只做对他有利的事。              | **海豚表演**：海豚跳圈不是因为热爱艺术，是因为跳完有鱼吃。                                                                      | **解决“动力”问题**。<br><br>  <br><br>科学的设计（KPI/OKR/股权）能让员工的私心和公司的目标重合。                           |

| **边际成本**<br><br>  <br><br>(Marginal Cost)           | **复制费**<br><br>  <br><br>再多做一个产品，需要**额外**花多少钱？（注意：不是平均成本）。 | **写代码 vs 开餐馆**：<br><br>  <br><br>软件开发完，多卖一份几乎不需要钱（边际成本≈0）；<br><br>  <br><br>餐馆多卖一份牛排，就得多买一块肉（边际成本高）。 | **解决“扩张”问题**。<br><br>  <br><br>它决定了你的业务能不能爆发式增长（Scale）。边际成本越低，越值得做大规模。                     |
|                                                     |                                                            |                                                                                                      |                                                                                            |
| **供需关系**<br><br>  <br><br>(Supply & Demand)         | **物以稀为贵**<br><br>  <br><br>价值不取决于你多辛苦，取决于市场缺不缺。            | **沙漠里的水**：<br><br>  <br><br>你在湖边卖水一文不值，搬到沙漠里就能卖天价，虽然水是一样的。                                           | **解决“定价与招聘”问题**。<br><br>  <br><br>为什么AI工程师工资高？不是因为他们更努力，是因为供不应求。管理必须顺应市场行情。                |

| [[代理人理论]]<br><br>  <br><br>(Principal-Agent Theory) | **保姆困境**<br><br>  <br><br>出钱的人（委托人）和干活的人（代理人）利益永远不一致。      | **装修房子**：<br><br>  <br><br>你是房主（想省钱、质量好），装修队（想省事、多赚材料费）。你不盯着，他大概率会偷工减料。                              | **解决“信任与监督”问题**。<br><br>  <br><br>承认人性本私。现代公司的董事会、审计、职业经理人制度，全是为了防止代理人（CEO/员工）坑委托人（股东/老板）。 |
