#  💡Summary  

> [!Info]
> 一句话说清楚
> 

**先把“所有进你微信的钱”分成四类：客户收入、经营成本、老板自取、税；再把“所有给研究生的钱”分成两类：工资还是劳务；最后给整个生意补上一个正式主体和一套台账。**

你现在最该补的，不是高深财务模型，而是这套最小闭环：

**一个主体，三个账户，四本台账。**

一个主体：个体户、个独或公司任选其一。  
三个账户：收款账户、付款账户、老板个人账户尽量分开。  
四本台账：客户台账、研究生结算台账、费用报销台账、老板往来台账。



| 知识点       | 本质在看什么               | 放到你工作室里是什么意思                              |
| --------- | -------------------- | ----------------------------------------- |
| 毛利        | 核心服务本身赚不赚钱           | 一个客户交 6000，你直接服务他的老师成本是 1800，那这单毛利就是 4200 |
| 净利        | 整个生意最后赚多少            | 扣掉推广、房租、管理、软件、售后后，最后真正剩下的钱                |
| 单客经济模型    | 每接一个客户值不值            | 一个客户收费、服务成本、获客成本、退款风险，加起来到底赚不赚            |
| 固定成本和变动成本 | 什么钱不接单也要花，什么钱跟单量一起变  | 房租、基础员工可能是固定成本；按单分成给研究生更像变动成本             |
| 盈亏平衡点     | 至少做多少单才不亏            | 比如一年固定开支 30 万，每单平均贡献 3000，那你至少要做 100 单    |
| 应收应付      | 钱该收但没收，该付但没付         | 家长尾款还没打给你，是应收；研究生报酬还没发，是应付                |
| 预收款       | 先收钱，服务以后做            | 家长先交全款，但志愿填报服务还没完成，这钱不能简单理解成“都已经赚到了”      |
| 预算        | 提前规划钱怎么花             | 今年目标 200 单，那推广预算给多少，人力预算给多少，自己先有盘子        |
| 现金储备      | 防止突然缺钱               | 高峰期前先备 3 到 6 个月固定开支，不然退款、淡季、投流失效时会慌       |
| [[税务]]意识  | 别把“赚到的钱”和“能自由拿走的钱”混了 | 有些钱看起来到账了，但里面有税、有员工报酬、有未来服务义务，不全是你自己的     |
