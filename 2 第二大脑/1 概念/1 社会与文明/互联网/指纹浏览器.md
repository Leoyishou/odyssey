# 💡 Summary  


> [!info]
> **比喻**：正常浏览器=全家用一张脸出门，容易被认亲戚。指纹浏览器=每个人戴假面具+变装+不同城市逛街，互不干扰。
> 


## 背景

网站（比如小红书、抖音网页版）不只看你的IP地址，还会偷偷收集上百种“指纹”信息来认人：
- 屏幕大小、分辨率、字体列表、浏览器插件、时区、硬件加速、甚至鼠标移动习惯。
- 这些组合起来超级独特，就像你的指纹，同一个电脑开多个账号，网站一眼就知道“这是同一个人在搞鬼”→账号关联→封禁风险。

## 指纹浏览器干啥？

它是个软件（比如[[AdsPower]]、Multilogin），帮你创建多个“独立浏览器环境”：

- 每个环境有**独一无二的指纹**（模拟不同电脑/手机配置）。
- 支持**独立代理IP**（换不同网络位置）。
- 一键切换账号，像开多个“虚拟电脑”一样隔离操作。

# 🪞Notes
**AdsPower** 和 **GoLogin** 与你本地的 **Claude Code**（Claude Desktop 或 Claude 的代码环境）配合最好，因为两者都有**官方原生 MCP（Model Context Protocol）支持**。这让你可以用自然语言直接指挥 Claude 自动化浏览器（创建/打开/关闭 profile、修改指纹、运行网页任务等），无需复杂编码。

### 为什么是这两个？

- **MCP 是关键**：Claude Desktop 通过 MCP Server 实现“AI 代理”式控制浏览器。$2025-2026$ 年，只有少数指纹浏览器官方提供了专用 MCP Server。
- 其他工具（如 Multilogin、Incogniton、Dolphin Anty）只支持传统 API（Selenium/Puppeteer/Playwright），你可以用 Claude 生成脚本调用，但不是无缝自然语言集成，效率低很多。
- BitBrowser 有 API，但没有官方 Claude MCP 支持（搜索结果只有通用 MCP 指南）。
