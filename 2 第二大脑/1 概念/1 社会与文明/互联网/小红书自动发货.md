# 小红书店铺自动发送兑换码调研报告

## 调研背景

您希望在小红书店铺销售咨询服务时，能够在用户下单后自动发送兑换码给用户。用户收到兑换码后，可以在您的咨询服务网站上输入兑换码完成预约。本报告调研了实现这一需求的可行方案。

## 调研结论

**小红书店铺自动发送兑换码是完全可行的**。目前主要有三种实现方案，其中最推荐的是使用第三方自动发货工具（如阿奇索），设置简单、成本低、无需开发。

---

## 方案一：第三方自动发货工具（推荐）

### 工具介绍

**阿奇索**是目前最主流的小红书虚拟商品自动发货工具，已在小红书服务市场上架，支持多种电商平台（淘宝、拼多多、闲鱼、京东、小红书等）的虚拟商品自动发货。

### 工作原理

买家在小红书付款下单后，系统通过聊天窗或短信，自动将兑换码发送给买家。整个过程无需人工干预，支持24小时自动发货，并自动更新发货状态。

### 费用

| 套餐 | 价格 | 说明 |
|------|------|------|
| 免费试用 | 0元 | 7天免费试用 |
| 月付 | 30元/月 | 按月付费 |
| 年付 | 138元/年 | 相当于11.5元/月 |

### 发货方式

阿奇索支持两种发货方式，可单选或同时使用：

| 发货方式 | 是否需要挂机 | 特点 |
|----------|--------------|------|
| 短信发货 | 否 | 无需电脑挂机，24小时自动发货，需另购短信包 |
| 千帆消息（聊天窗） | 是 | 需要电脑下载发货助手并保持在线 |

### 设置步骤

1. **订购服务**：登录小红书商家后台（千帆平台），进入服务市场，搜索"阿奇索"或"自动发货"，订购服务
2. **绑定91卡券仓库**：91卡券仓库作为资产中心，可统一管理多平台多店铺的卡密
3. **创建卡种**：在91卡券仓库中创建一个卡种（如"咨询服务兑换码"）
4. **添加兑换码**：将您网站生成的兑换码批量导入到该卡种中
5. **设置自动发货**：选择需要自动发货的商品，关联对应的卡种，填写使用说明
6. **选择发货方式**：推荐选择"短信发货"，无需挂机

### 发货效果示例

买家下单后会自动收到类似以下内容的消息：

> Hi，您的订单：P71608794685136017  
> 兑换码：ABC123XYZ  
> 使用方法：请访问 xxx.com/booking，输入兑换码完成预约  
> 感谢惠顾~期待与您再次相遇

## 方案二：小红书官方开放平台 API

### 平台介绍

小红书提供了官方开放平台（ARK平台），支持第三方开发者和自研商家通过API接入。平台提供了Webhook回调机制，可以在订单创建时通知商家系统。

### Webhook 回调机制

小红书提供了**库存变动回调（订单创建）**接口：当购买者在小红书成功创建订单后，小红书系统会通过该回调接口通知第三方商家。商家可以在收到回调后，自动发送兑换码给用户。

### 回调数据示例

```json
{
    "package_id": "P124394374937984",
    "time": 14437942734983,
    "pay_amount": 176,
    "item_list": [
        {
            "item_id": "accadfereadrercad4eerrdafe1",
            "item_name": "咨询服务",
            "qty": 1,
            "pay_price": 88
        }
    ]
}
```

### 配置步骤

1. 在ARK平台申请开发者资质
2. 配置回调URL：ARK → 开发者 → 回调URL → OPEN API通用
3. 开发接口接收小红书的回调请求
4. 收到订单回调后，调用您网站的API自动发送兑换码给用户

### 重试机制

如果回调失败或超时，小红书会自动重试：第一次重试在10秒后，第二次重试在30秒后。

### 注意事项

- 需要申请开发者资质，有一定门槛
- 回调的订单可能处于未付款状态，需要额外判断
- 需要一定的技术开发能力

| 方案 | 优点 | 缺点 | 适用场景 | 成本 |
|------|------|------|----------|------|
| 第三方工具（阿奇索） | 设置简单，无需开发，功能完善 | 有月费/年费 | 个人卖家、小商家 | 月30元/年138元 |
| 官方API接入 | 灵活度高，可深度定制 | 需要开发，有申请门槛 | 品牌商家、有技术团队 | 免费（需开发成本） |
| 服务市场工具 | 官方支持，集成度高 | 功能可能有限 | 各类卖家 | 视具体工具而定 |

## 推荐方案

对于您的情况（小红书店铺卖咨询服务，需要自动发送兑换码），**强烈推荐使用第三方工具（阿奇索）**。

### 推荐理由

1. **设置简单**：无需任何开发，只需在小红书服务市场订购即可使用
2. **成本低**：月30元或年138元，有七天免费试用期
3. **功能完善**：支持卡密管理、短信发货、24小时自动发货
4. **无需挂机**：选择短信发货方式，无需电脑保持在线
5. **跨平台管理**：91卡券仓库可统一管理多平台的卡密
