#  💡Summary  

> [!Info]
> 一句话说清楚
> 

谱上音名 -> 键盘位置 -> 这一小段手怎么覆盖最省事 -> 指法

|右手手位|记忆方式|训练目的|
|---|---|---|
|1 指在 C|C-D-E-F-G|最基础的 C 位，建立白键五指顺序|
|1 指在 G|G-A-B-C-D|右手整体向右移动，扩大音域|
|1 指在 F|F-G-A-B-C，遇到 F 大调时 B 常变 B♭|适应新位置，同时接触调号/黑键|
|其他临时移动|看谱面和指法决定，不一定是一整首固定手位|打破“永远五个手指固定不动”的习惯|
