**0. 情绪命题**
先不是写旋律，而是定一句“创作宪法”：

> 明明还爱，但知道必须放手。  
> 不哭喊，不控诉，温柔、克制、有距离。

这句话会成为后面所有选择的裁判。只要某个音、某句词、某个鼓点太激动，就会被删掉。

**1. 速度**
制作人先问：这个人说话是急的，还是慢的？

这种情绪不能太快。太快会像已经放下了，太慢又容易变成苦情宣泄。所以会选一个中慢速，让每句尾巴有停顿，让听众听见“忍住”的感觉。

| 选择 | 情绪效果 |
|---|---|
| 快速 | 逃离、释怀、轻盈 |
| 中慢速 | 克制、回望、还舍不得 |
| 很慢 | 痛苦、沉重、哭诉 |

《富士山下》这种气质更接近中慢速。

**2. 调性和音区**
然后问：声音应该亮，还是暗？

如果太明亮，会像祝福或释然；如果太暗，会像崩溃。它需要的是“冷色但不绝望”。所以钢琴、人声、弦乐都不会特别尖锐，而是偏中低音区，温柔、厚一点。

这一步决定的是整首歌的“天气”。

**3. 和弦骨架**
接着搭和声。这里不是为了炫和弦，而是为了制造一种感觉：

> 我每次快要回到稳定，都不完全落地。

所以和弦会有“要解决但不马上解决”的倾向。听感上就是：一直在往前走，但心里还悬着。

| 和弦功能 | 情绪对应 |
|---|---|
| 稳定和弦 | 我接受现实 |
| 小调/转暗 | 我还难过 |
| 悬而未决 | 我说不出口 |
| 回到主和弦 | 我必须放手 |

这就是“和弦不是数学，是情绪路线图”。

**4. 旋律动机**
然后才开始写旋律。制作人会问：这个人是喊出来，还是咽回去？

这种歌的旋律一般不会一直往上冲。上冲太像爆发。它会更常用：

| 旋律动作 | 听感 |
|---|---|
| 下行 | 叹气、放下、无力 |
| 停顿 | 忍住、不说完 |
| 长音 | 情绪卡住 |
| 小范围移动 | 克制、像说话 |
| 偶尔上扬 | 情绪短暂涌上来 |

所以你会感觉它不是“唱旋律”，而是“把一句话唱到快说不下去”。

**5. 歌曲结构**
接下来把动机扩成段落。

一个典型抒情歌结构可能是：

| 段落 | 制作目的 |
|---|---|
| Intro | 先给空间，不急着讲故事 |
| Verse | 低声叙述，情绪还压着 |
| Pre-chorus | 情绪开始往上推 |
| Chorus | 主题真正说出来，但仍克制 |
| Bridge | 换角度，给一次更深的情绪 |
| Final chorus | 回到主题，但听众已经被带进去 |

重点是：副歌不是突然变大声，而是“终于说到核心”。

**6. 歌词意象**
如果旋律已经有了，填词人会问：这个情绪不能直接说“我舍不得你”，那要用什么画面替代？

于是会找：

| 抽象情绪 | 可能变成的歌词材料 |
|---|---|
| 冷 | 雪、风、雨、山、夜 |
| 距离 | 车站、旅途、异地、风景 |
| 放手 | 归还、送别、离开、转身 |
| 余温 | 衣服、气味、旧物、回忆 |

这就是高级流行歌词的关键：**不直接解释情绪，而是让物件替你承受情绪。**

**7. 编曲雏形**
然后编曲人进来。此时他不能问“我能加什么”，而要问“我不能破坏什么”。

这种歌的编曲原则大概是：

```text
人声是主角
钢琴负责骨架
弦乐负责情绪拉长
鼓不要太存在
低频要稳，但不能压人
留白比填满更重要
```

如果编曲太满，听众会注意乐器，而不是注意那个“忍住的人”。

**8. 人声设计**
歌手录音时，制作人会控制表演尺度。

不是“唱得越有感情越好”，而是：

| 唱法 | 是否适合 |
|---|---|
| 大哭式 | 太直接，破坏克制 |
| 炫技式 | 注意力跑到技巧 |
| 平淡无波 | 情绪不够 |
| 压着唱 | 最接近主题 |
| 句尾轻轻放掉 | 很适合“放手感” |

陈奕迅这类歌最厉害的地方就是：他常常不是把情绪唱爆，而是让你听见情绪被压住。

**9. 混音**
最后混音不是简单调音量，而是决定“听众站在哪里”。

这种歌通常会让：

```text
人声靠前
钢琴在中间
弦乐在后面铺开
鼓和低频退后
混响有空间，但不能糊
```

听感像什么？像一个人在你面前说话，背后是很大的风景。

**10. 成品判断**
最后制作人会用一句话验收：

> 这首歌有没有让人感觉：他没有崩溃，但他真的很难过？

如果答案是有，制作就是成立的。

所以完整时间线其实是：

```text
情绪命题
-> 速度
-> 调性/音区
-> 和弦路线
-> 旋律动机
-> 歌曲结构
-> 歌词意象
-> 编曲留白
-> 人声表演
-> 混音空间
-> 成品情绪校准
```

你作为初学者可以先记一个最小模型：

```text
我想表达什么？
这个人说话快不快？
声音亮不亮？
旋律是往上冲，还是往下叹？
伴奏是托住人声，还是抢走注意力？
```

这五个问题，已经比“先学一堆和弦”更接近真正的制作人思维。
