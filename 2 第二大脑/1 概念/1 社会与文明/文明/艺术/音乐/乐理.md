# 🪞Notes


| 节点名称           | 类型        | 父节点        | 说明             |               |             |                 |
| -------------- | --------- | ---------- | -------------- | ------------- | ----------- | --------------- |
| score-partwise | Object    | Root       | 整个乐谱的根节点       |               |             |                 |
|                | part-list | Object     | score-partwise | 乐器/声部定义列表     |             |                 |
|                |           | score-part | Array          | part-list     | 每个乐器/声部的元信息 |                 |
|                | part      | Array      | score-partwise | 实际的音乐内容（每个声部） |             |                 |
|                |           | measure    | Array          | part          | 小节（时间序列容器）  |                 |
|                |           |            | attributes     | Object        | measure     | 小节属性（调号、拍号、谱号等） |
|                |           |            | note           | Array         | measure     | 音符或休止符          |
|                |           |            | direction      | Object        | measure     | 表情、速度、力度等       |
|                |           |            | barline        | Object        | measure     | 小节线信息（终止、重复等）   |

## note 结构

|字段|类型|是否必填|说明|
|---|---|---|---|
|pitch|Object|否|音高（与 rest 互斥）|
|rest|Boolean|否|是否为休止符|
|duration|Number|是|时值（基于 divisions）|
|voice|Integer|否|声部编号|
|type|String|否|音符类型（quarter、half 等）|

---

## attributes 结构

|字段|类型|说明|
|---|---|---|
|divisions|Number|时间单位|
|key|Object|调号|
|time|Object|拍号|
|clef|Object|谱号|
