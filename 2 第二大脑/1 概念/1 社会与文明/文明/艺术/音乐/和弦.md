#  💡Summary  

> [!Info]
> 一句话说清楚
> 


和弦的定义是三个间距刚好等于一的 note 的组合 和弦里的三个音既可以同时发出，也可以依次发出，这两种发声方式对应乐理里的两个概念： 
1. 柱式和弦：三个及以上音同时发声，听感饱满扎实，像一堵“音墙”，是和声伴奏里最常用的形式，比如钢琴左手的伴奏和弦、吉他扫弦的和弦。 
2. 分解和弦：三个及以上音先后依次发声，听感流畅灵动，像一串“音的流水”，常见于钢琴的琶音、吉他的分解伴奏型，以及小提琴的旋律化伴奏。 要不要我帮你整理一份柱式和弦与分解和弦的常用乐器演奏示例，让你更直观地区分两者的用法？

# 🪞Notes

`Am` 是 **A minor**，中文叫 **A 小三和弦** 或 **A 小调和弦**。

它由三个音组成：

| 和弦 | 组成音 | 听感 |
|---|---|---|
| C | C - E - G | 明亮、稳定 |
| Am | A - C - E | 柔和、有一点忧郁 |
| F | F - A - C | 温暖、展开 |
| G | G - B - D | 有推动感，想回到 C |

所以 `C - Am - F - G` 里的 `Am` 不是“A 米”，而是：

```text
A minor = A 小三和弦 = A + C + E
```

在钢琴上，全是白键。左手可以先只弹 `A`，右手弹 `A-C-E`。



## 和弦骨架

只用两个音，也能让耳朵听出“稳、回家、推动、紧张、落地”。
**C 大调里的“和声骨架”和“紧张-解决”**。

| 组合              | 乐理上是什么              | 听感为什么这样                  |
| --------------- | ------------------- | ------------------------ |
| **C(do)+E(mi)** | C 大三和弦的 1 音 + 3 音   | 已经能听出 C 大调的“家”           |
| **D(re)+F(fa)** | 2 音 + 4 音，紧张音程      | 它很容易往 C+E 解决             |
| C(do)+G(sol)    | 纯五度，C 和弦的 1 音 + 5 音 | 很空、很稳，像根基                |
| C(do)+C(do)     | 八度                  | 最像“定住了”                  |
| G(sol)+D(re)    | G 的纯五度，属音骨架         | G 是 C 大调的属音，有往前推的感觉      |
| G(sol)+G(sol)   | 属音八度                | 不像 C 那么落地，像还没完           |
| C(do)+E(mi)     | 1 音 + 3 音           | 从 D+F 回到 C+E，就有“落地”感     |
| E(mi)+G(sol)    | C 和弦的 3 音 + 5 音     | 还算稳定，但没有 C 做根音，所以没那么“回家” |
