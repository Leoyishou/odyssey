# 💡 Summary


> [!info]
> 
> 不是每个流行歌手都会“系统地”去学这些教材，但顶级歌手的发声逻辑最终都会“殊途同归”到这些体系里。
> 这就像很多顶级大厨没读过《厨艺化学》，但他们炒菜时对火候和分子变化的控制，完全符合科学原理。
>

## 为什么学体系

### 1. “学院派”与“工业化”歌手：必须学

这类歌手（尤其是 **K-Pop 练习生**、**百老汇音乐剧演员**）几乎是泡在这些体系里长大的。

- **原因：** 唱跳强度大，必须用最省力、最科学的方式（如 **IVA**）来保证高音稳。
    
- **典型：** 像 SM、YG 这种大公司的声乐老师，很多本身就是 IVA 或 EVT 的认证教官。他们追求的是**高稳定性**和**可复制性**。
    

### 2. “天赋流”与“野路子”歌手：不一定学，但会“悟”

很多伟大的歌手（比如早期的周杰伦、王菲，或者很多摇滚老炮）在出道时并不知道什么是 CVT 或 EVT。

- **现状：** 他们靠超常的天赋和大量的实践，摸索出了一套适合自己的发声方式。
    
- **风险：** 这种“野路子”如果悟对了，就是独一无二的音色；如果悟错了，或者长期疲劳演唱，嗓子很容易出问题（倒嗓）。
    
- **后续：** 很多这类歌手在嗓子受伤后，会专门去找 **IVA** 或 **SLS** 的老师进行“声带修复”和二次开发。
    

### 3. “机能怪”与“技术控”：深研派

这类歌手对唱歌有种“极客精神”，他们会主动去钻研这些体系。

- **典型：** 比如国内的**张杰、谭维维、迪玛希**等。他们会去接触不同的体系（比如张杰就曾赴美学习 SLS 体系，这也是 IVA 的前身），通过技术迭代让自己的音域更宽、高音更厚。



___

- **音调（Pitch）：** 这些体系通过训练声带肌肉，让你能唱出以前唱不到的高音。
    
- **音色（Tone）：** 这些体系通过调整声道形状（喉咙的空间），让你能自由调节声音的明暗、薄厚和质感。

**流行音乐发展简史概览**

| **时期**      | **音乐类型/流派**                   | **简介与核心特征**                      | **代表人物/现象**                |            |
| ----------- | ----------------------------- | -------------------------------- | -------------------------- | ---------- |
| 19世纪末-1940s | **叮砰巷** $(Tin Pan Alley)$     | 流行音乐工业的雏形，标准化的商业歌曲创作模式。          | 纽约乐谱出版业                    |            |
|             | **爵士与蓝调** $(Jazz \& Blues)$   | 源于非裔美国人，第一种具有全球影响力的流行形式。         | 路易斯·阿姆斯特朗等                 |            |
|             | **摇摆乐** $(Swing)$             | 由大乐队（$Big Band$）演奏，适合广播传播。       | 本尼·古德曼等                    |            |
| 1950s       | **摇滚乐** $(Rock \& Roll)$      | 融合$R\&B$与乡村音乐，确立电吉他地位，充满性张力与叛逆。  | 猫王 $(Elvis Presley)$、比尔·黑利 |            |
| 1960s       | **英伦入侵** $(British Invasion)$ | 重新定义“乐队”概念（全员创作），旋律优美。           | 披头士 $(The Beatles)$        | 《Hey Jude》 |
|             | **民谣** $(Folk)$               | 强调歌词的文学性与社会表达。                   | 鲍勃·迪伦                      |            |
|             | [[灵魂乐 (Soul)]]                | 黑人音乐进入主流市场，情感充沛。                 | 摩城唱片 $(Motown)$            |            |
| 1970s       | **迪斯科** $(Disco)$             | 强调节奏、舞曲文化与享乐主义，电子舞曲的基石。          | $Bee Gees$                 |            |
|             | **朋克** $(Punk)$               | 对商业摇滚的反叛，结构简单（三和弦）、充满愤怒。         | 性手枪 $(Sex Pistols)$        |            |
|             | **重金属/前卫摇滚**                  | 追求艺术化、技术复杂性与体育馆规模的演出。            | $Led Zeppelin, Pink Floyd$ |            |
| 1980s       | **视觉流行** $(Visual Pop)$       | $MTV$时代产物，强调“看音乐”，集视觉、舞蹈、音乐于一体。  | 迈克尔·杰克逊、麦当娜                |            |
|             | **合成器流行** $(Synth-pop)$       | 大量使用合成器与鼓机，声音具有“塑料感”和未来感。        | $Depeche Mode, A-ha$       |            |
|             | **嘻哈** $(Hip-Hop)$ [早期]       | 起源于布朗克斯街头派对，开始向主流渗透。             | $Run-D.M.C.$               |            |
| 1990s       | **嘻哈** $(Hip-Hop)$ [爆发期]      | 成为全球销量巨头，统治流行文化。                 | $2Pac, Jay-Z$              |            |
|             | **垃圾摇滚** $(Grunge)$           | 另类摇滚的分支，回归原始力量与颓废感。              | $Nirvana$                  |            |
|             | **青少年流行** $(Teen Pop)$        | 针对年轻市场的偶像团体与歌手狂潮。                | 后街男孩、小甜甜布兰妮                |            |
| 2000s-至今    | **电子舞曲** $(EDM)$              | $DJ$成为超级巨星，不仅是伴奏者。               | $Avicii, Calvin Harris$    |            |
|             | $K-Pop$ / **拉丁流行**            | 非英语音乐的全球化崛起，去中心化趋势。              | $BTS, Despacito$           |            |
|             | **短视频神曲** $(TikTok Pop)$      | 为算法推荐而生，结构短促，副歌前置（$Hook-first$）。 | 病毒式传播歌曲                    |            |
