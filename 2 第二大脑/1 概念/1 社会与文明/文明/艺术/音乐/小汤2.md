#  💡Summary  

> [!Info]
> 一句话说清楚
> 

| 概念 (Concept) | 英文 (English)  | 中文释义                                                                            |
| ------------ | ------------- | ------------------------------------------------------------------------------- |
| 八分音符         | Eighth note   | 时值为四分音符一半的音符，符头实心带一条符尾（或与相邻八分音符用横梁连起来）。在 4/4 拍里，一拍可放两个八分音符，常念作"ti-ti"。          |
| 升号           | Sharp (♯)     | 写在音符前的变音记号，把该音升高半音。效力持续到当前小节结束。                                                 |
| 降号           | Flat (♭)      | 写在音符前的变音记号，把该音降低半音。同样在该小节内持续有效。                                                 |
| 还原号          | Natural (♮)   | 取消之前的升号或降号（包括调号里的），让音回到本位音。                                                     |
| 调号           | Key signature | 谱号后、拍号前列出的一组升号或降号，规定整首曲子里哪些音默认要升或降，从而确定调性。小汤二里出现 F 大调（一个降号 B♭）和 G 大调（一个升号 F♯）。  |
| 和弦           | Chord         | 同时（或近似同时）发响的两个或两个以上不同音高的音。三个音叠成的"三和弦"最常见；分解弹奏叫"分解和弦 (broken chord / arpeggio)"。 |

预习建议：先把升号 / 降号 / 还原号三个变音记号区分清楚，再去看调号——调号本质就是"提前声明这一首曲子里哪几个音要升或降"。八分音符配合 2/4、3/4、4/4 节拍数一数"1 and 2 and"，和弦从两音和弦练起会比较平滑。
