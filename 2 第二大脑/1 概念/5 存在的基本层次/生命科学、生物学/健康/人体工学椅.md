# Summary

刚买人体工学椅，可能需要 1–2 周来适应，因为之前的坐姿习惯会“惯性牵引”。

# Notes
## 🪑 人体工学椅调节 Checklist

### 1. 椅子高度

- [x] 双脚能平放地面，膝盖角度约 90°–100°
- [x] 大腿与地面平行或略微向下

### 2. 靠背 & 腰托

- [x] 臀部坐到椅子最里面
- [x] 腰托正好贴合腰椎曲线（不是顶在屁股上，也不是顶到背中间）
- [ ] 靠背角度略微后仰 100°–110°

### 3. 扶手

- [ ] 肘部自然弯曲 90°–100° 时刚好能搭在扶手上
- [ ] 双肩放松、不耸肩
- [ ] 前臂能与键盘保持水平或略微向下

### 4. 桌面/显示器

- [ ] 桌面高度与肘部齐平
- [ ] 显示器上沿大约与眼睛水平或略低 2–3 cm
- [ ] 眼睛到屏幕距离约一臂长

### 5. 头枕（如果有）

- [ ] 调整到贴合颈部或后脑勺
- [ ] 只在休息或后仰时使用

### 6. 使用习惯

- [ ] 每隔 40–60 分钟起身活动 2–5 分钟
- [ ] 避免长时间前倾、盘腿
- [ ] 电脑使用时保持“腰贴靠背、肩放松、颈自然”的三点
