#  💡Summary  

![image.png|1000](https://imagehosting4picgo.oss-cn-beijing.aliyuncs.com/imagehosting/20260412211931522.png)


视线：关键点：视线带动肩膀 -> 肩膀带动胯 -> 胯带动板。锁死肩膀： 低头会导致颈椎僵硬，肩膀转不动，身体卡住。

前刃：是顶胯刹车。如果只做“提踵”（像跳芭蕾舞），会累死且站不稳； 如果您只做“膝盖前顶“（像下跪），您的脚后跟会在鞋子里提起来（Heel Lift），导致力量传导失效。 这其中的力学秘密在于单板雪鞋的构造—鞋舌（Tongue）。

换刃：真正流畅的换刃，板子不是像一块铁板一样整体翻转，而是像扭毛巾一样发生“扭转形变” (Torsional Twist)。这就要求脚的施力必须有时间差：前脚先动（导向），后脚跟进（随动）。前脚先压/勾 -> 等板头转过去 -> 后脚再跟上。• 中间这 0.5秒的延迟，就是所谓“扭转”发生的时间，也是换刃顺滑的关键。

防摔姿势: 永远不要用手掌直接撑地！ 握拳护胸，用小臂侧面着地。

滚落线：下去的那条路线，就是滚落线。 它永远指向山坡最陡、下降最快的方向。 它是重力对拉扯力最大的方向。

刻滑（Carving）： 你的板子立起来的角度很高（High Edge Angle）。 板刃（钢边）像一把锋利的刀，深深地切入雪里。 板子不再横
