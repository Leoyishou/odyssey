# **向死而生**（海德格尔）

知道自己终将死亡，反而让生命变得真实。就像deadline让你效率爆表一样。海德格尔说，只有真正面对死亡的必然性，你才会停止随波逐流，开始过真正属于自己的生活。不是消极厌世，而是"正因为有限，所以珍贵"。
