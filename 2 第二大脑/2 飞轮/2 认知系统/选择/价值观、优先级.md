## 自由、航海、宝藏

| 支柱   | 作者所指                              | 快乐来源               | 需要什么             | 门槛     | 潜在代价                  |
| ---- | --------------------------------- | ------------------ | ---------------- | ------ | --------------------- |
| 自由   | 躺平、极简生活，降低消费与社会关系束缚，可以随时辞职、旅行或换城市 | 自主权、爱好、及时行乐带来的精神快乐 | 低物欲、较少责任、接受不稳定生活 | 作者认为最低 | 收入和保障下降，可能失去稳定关系与长期积累 |
| 航海   | 搞事业：确定方向、制定规划、寻找伙伴并持续行动           | 目标感、价值感、对未来的期待     | 规划能力、执行力、长期投入    | 作者认为中等 | 事业压力、失败风险，可能重新陷入绩优主义  |
| 宝藏   | 拥有足够的资产、收入和闲暇时间，享受物质生活            | 安全感、消费体验和物质快乐      | 钱，同时还要有时间花钱      | 作者认为最高 | 容易依赖财富；“有钱但没时间”也不成立   |
|      |                                   |                    |                  |        |                       |
| 组合状态 | 短期满足自由，长期经营事业，偶尔享受消费              | 同时获得精神快乐、人生意义和物质体验 | 在三个维度之间分配时间和资源   | 因人而异   | 三者可能争夺同一份时间与精力        |
