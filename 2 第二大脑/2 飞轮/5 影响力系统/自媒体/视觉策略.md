# 🪞Notes
「视觉策略」是指在内容创作和传播中，通过视觉元素的选择和设计来达成特定目标的方法论。

在你今天的对话语境中（小红书封面设计），视觉策略指的是：
| 维度     | 示例                                       |
| :------- | :----------------------------------------- |
| 风格选择 | 手绘白板风 vs 上下对比漫画风 vs 杂志大字风 |
| 色彩搭配 | 纯白背景+黑色文字=高级感；渐变背景=科技感  |
| 构图布局 | 留白比例、元素位置、视觉焦点               |
| 信息层级 | 标题>副标题>正文的字号对比                 |
| 平台适配 | 小红书竖版 3:4、抖音 9:16、公众号横版      |

核心目的：
- 🎯 停留 — 在信息流中抓住注意力（3秒法则）
- 🎯 传达 — 快速传递核心信息
- 🎯 转化 — 引导用户点击、收藏、关注

你今天做的「上下对比漫画风格」就是一种视觉策略 — 用反差制造趣味，用简约留白提升高级感。
