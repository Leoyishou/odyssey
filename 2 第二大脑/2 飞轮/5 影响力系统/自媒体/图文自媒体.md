健身新手常见的认知误区和疑惑

动作类
| 疑惑 | 真相 |
|---|---|
| 深蹲"膝盖不能超脚尖" | 完全是误传。膝盖超不超取决于身体比例，刻意不超反而伤腰 |
| 卧推胸没感觉，三头先酸 | 木桶效应，可能是肩胛骨没收紧、握距太窄 |
| 硬拉腰疼 | 不是"腰不好"，是臀腿没发力，腰在代偿 |
| 俯卧撑手肘该贴身还是外展 | 45度最安全，90度外展伤肩，完全贴身练三头 |
训练理念类
| 疑惑 | 真相 |
|---|---|
| 不酸 = 没练到？ | 酸痛≠有效，延迟酸痛只说明肌肉不适应 |
| 练得越多越好？ | 肌肉是休息时生长的，过度训练适得其反 |
| 每天练腹肌？ | 腹肌也是肌肉，需要48小时恢复 |
| 有氧会掉肌肉？ | 适量有氧不会，空腹长时间有氧才危险 |
饮食/补剂类
| 疑惑 | 真相 |
|---|---|
| 练完30分钟必须喝蛋白粉？ | "窗口期"被夸大了，全天蛋白质总量更重要 |
| 只做仰卧起坐能减肚子？ | 局部减脂是伪概念，脂肪全身一起掉 |
心理类
| 疑惑 | 真相 |
|---|---|
| 体重不降 = 没效果？ | 可能在增肌减脂同时进行，看围度和体脂率 |
| 女生练力量会变金刚芭比？ | 女性睾酮只有男性的1/15，想变壮很难 |

# 🪞Notes

| 术语 | 定义 |
|---|---|
| **想法博物馆 (Idea Museum)** | 创作者用来收集和筛选高密度创意、笔记及灵感的系统或工具。 |
| **思想密度 (Idea Density)** | 单位内容中所包含的有效信息和高质量观点的集中程度。 |
| **素材库 (Swipe File)** | 营销和创作术语，指经过严格筛选的笔记、优秀案例和灵感收集文档。 |
| **好奇心缺口 (Curiosity Gap)** | 在引言中通过提出问题或反直觉观点，使读者产生“想知道答案”的心理落差。 |
| **包装 (Packaging)** | 对内容进行的标题优化、视觉呈现及结构设计，旨在提高点击率（CTR）。 |
| **响亮的内容 (Loud Content)** | 具有强烈钩子、明确问题、独特解决方案及高度自信立场的内容。 |
| **流量机制 (Traffic Mechanisms)** | 指通过回复、引用、转发、群聊分享及私信等手段主动获取关注的方法。 |
| **逆向工程 (Reverse Engineering)** | 通过拆解优秀爆款内容的宏观结构与心理学机制，提炼可复用范式的过程。 |
| **借力权威 (Leveraging Authority)** | 引用名人的观点或谈论热门创作者，以吸引其原有受众并增加自身可信度的策略。 |
| **反愿景 (Anti-vision)** | 明确界定自己不希望成为的样子或不认同的行为，从而反向推导出清晰的愿景。 |
